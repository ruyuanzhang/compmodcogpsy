# 6.5.2 精神疾病的应用

**漂移扩散模型在精神疾病研究中的应用**

漂移扩散模型近年来在精神疾病研究中得到了广泛应用。通过对患者决策过程中的证据积累机制进行建模，漂移扩散模型能够揭示精神疾病患者在认知控制、决策偏差及其潜在的神经机制中的差异。漂移扩散模型不仅为基础研究提供了深入的理论工具，也为临床诊断和个性化治疗方案提供了实用的指导。

**1. 精神疾病中的认知偏差与决策机制**

精神疾病患者在决策中常表现出反应迟缓、注意偏向、认知控制不足、过度谨慎或冲动选择，但这些表现未必源于同一种认知缺陷。例如，反应变慢既可能来自证据积累速度下降，也可能源于决策阈值提高，或刺激编码与运动执行时间延长。White等（2010）较早提出，可用扩散模型将临床群体的反应时—正确率差异分解为决策与非决策成分。此后，研究重点逐渐从“患者是否更慢”转向“哪个计算环节发生了改变”。其中，漂移率 (v) 表示证据积累速率，边界间距 (a) 反映决策谨慎性，起始点 (z) 表示反应前的初始偏向，非决策时间 (t₀ 则概括刺激编码和运动执行等过程。\
抑郁研究主要关注精神运动迟滞、认知控制和奖赏反应性。Lawlor等（2020）发现，重性抑郁障碍患者的漂移率较低、决策边界较宽，说明其反应变慢同时涉及证据积累效率下降和决策更加谨慎。焦虑研究则着重区分威胁偏向来自信息加工还是先验倾向。Ozturk等（2024）发现，高焦虑主要与起始点向威胁边界偏移有关，而非漂移率改变；Dillon等（2022）却发现，社会焦虑障碍患者在概率奖赏任务中的证据积累更快。这表明漂移率反映的是特定任务情境下的信息利用方式，而非疾病严重程度的通用指标。在精神分裂症等精神病性障碍中，DDM常用于分解认知控制任务中的缓慢与错误。Smucny等（2023）发现，精神分裂症患者在高控制需求条件下漂移率较低，且漂移率与背外侧前额叶激活的关系发生改变。Shen等（2024）进一步发现，精神病患者的主动控制漂移率较低，而患者及其一级亲属在低频序列中的非决策时间更长；模型参数比原始行为指标更能区分群体，并与功能结局相关，显示出作为中间表型的潜力。其他障碍的研究也表明，临床“犹豫”不能简单归结为阈值升高。Chen等（2022）发现，强迫症患者的反应迟缓主要与证据积累效率降低有关，边界则无显著差异。Grennan等（2023）在身体变形障碍中发现了平均反应时未能揭示的非决策过程及其药物调节效应。ADHD通常表现为任务相关信息提取效率下降，但边界和非决策时间也可能受到强化或药物影响。Pirrone等（2017）则发现，自闭症成人的反应较慢主要源于边界更宽和非决策时间更长，而非漂移率降低。跨诊断研究进一步显示，证据积累效率下降可跨越精神分裂症、双相障碍和ADHD等诊断类别，并与总体症状负担和冲动性相关，但这一结论仍需借助更丰富的任务和完整模型验证（Sripada & Weigard, 2021）。\
总体而言，精神疾病中的DDM参数不存在固定方向。相似的反应迟缓可能分别源于漂移率降低、边界增宽或非决策时间延长。DDM的主要价值并非为每种疾病寻找单一的异常参数，而是揭示特定任务中的行为差异由哪些决策成分共同产生。

**2. 优势和局限性**

* 优势：漂移扩散模型在精神疾病研究中的优势主要体现在其精确性、多样化应用和临床相关性。首先，漂移扩散模型提供了一种精确的方法来量化决策过程中的认知机制，使研究人员能够通过数学建模分析复杂的心理现象。其次，该模型适用于多种类型的认知任务，使其在多种精神疾病的研究中均能发挥作用，提供丰富的洞察。最后，漂移扩散模型的应用不仅限于理论研究，还能够为临床实践提供重要指导，帮助制定更有效的治疗策略，促进个性化干预。
* 局限性：尽管漂移扩散模型在精神疾病研究中展现了显著的优势，但它也有一些局限性。首先，漂移扩散模型的模型假设较为简化。例如，漂移扩散模型假设证据积累过程是线性且独立的，这可能不足以捕捉精神疾病患者在复杂情境下的决策过程。精神疾病的认知过程通常涉及多种因素的相互作用，而漂移扩散模型对这些复杂因素的整合能力有限，可能会导致模型的结果无法完全反映现实中的认知行为。 其次，漂移扩散模型在处理个体差异方面也存在一定局限性。精神疾病患者的个体表现差异巨大，尤其是对于精神分裂症等症状复杂的疾病，单一的漂移扩散模型可能难以涵盖所有患者的行为特征。模型的泛化能力可能受到患者个体差异的限制，这使得研究者在应用漂移扩散模型时需要根据具体情况进行适当的调整。

**3. 未来发展方向**

未来漂移扩散模型在精神疾病中的应用有望进一步扩展。首先，漂移扩散模型可与其他模型（如强化学习模型、神经网络模型等）结合，以更全面地理解精神疾病患者的决策机制。如将漂移扩散模型与强化学习模型结合，有助于解析精神分裂症患者在复杂反馈任务中的行为模式。另外，基于漂移扩散模型的数据分析，未来的研究可以推动个性化干预策略的发展。通过分析患者的决策模式，设计针对性的认知训练或药物干预方案，将有助于进一步提升治疗效果。。

漂移扩散模型为精神疾病的认知和决策过程研究提供了独特的视角和工具。通过揭示精神疾病患者在证据积累、决策速度和认知控制上的偏差，漂移扩散模型不仅为基础研究提供了重要的理论支持，也为临床实践提供了指导。未来的研究有望继续推动漂移扩散模型在精神疾病诊断、评估和治疗中的广泛应用。

**实例应用**

我们以Daniel G. Dillon等（2024）文章为例，看DDM如何在精神疾病分析应用中实现。

抑郁症常伴随快感缺失和奖赏反应性降低，但概率奖赏任务中的“奖赏偏向较弱”并不只有一种解释。它既可能意味着个体未能根据反馈形成对高奖赏反应的偏向，也可能来自刺激辨别困难、证据积累效率下降或作答策略差异。因此，要理解抑郁症中的奖赏加工异常，需要进一步区分当前选择过程与基于反馈的学习过程。

为探讨这一问题，Dillon等（2024）分析了未用药、正在寻求治疗的重性抑郁障碍（major depressive disorder, MDD）患者在概率奖赏任务（probabilistic reward task, PRT）中的表现。研究者比较了传统行为指标、层次漂移扩散模型（hierarchical drift-diffusion model, HDDM）、强化学习漂移扩散模型（reinforcement learning drift-diffusion model, RLDDM）和强化学习“信念模型”，以判断任务表现主要反映决策偏向还是奖赏学习。此外，他们还考察了模型参数的内部一致性、重测信度，以及这些指标能否探索性预测安慰剂或安非他酮治疗反应。经过数据质量控制后，第一次和第二次测量分别纳入49人和44人，两次测量均合格者为34人。

在PRT中，每个试次先呈现一张面孔，随后在嘴部位置短暂呈现长度略有差异的线段。被试需要判断线段较长还是较短。两类刺激出现的概率相同，但正确识别其中一类刺激获得奖励的次数约为另一类的3倍。奖励更频繁的刺激称为富刺激（rich stimulus），另一类称为贫刺激（lean stimulus）。随着任务进行，被试通常会逐渐增加富刺激反应，从而形成正向反应偏向。该任务包含两个相互关联但含义不同的传统指标：反应偏向反映个体选择富刺激反应的倾向，辨别力则反映其区分长、短刺激的能力。前者常被用作奖赏反应性的指标，后者则更多反映知觉证据质量。将两者分开十分重要，因为获得更多奖励既可能依赖对富刺激的偏向，也可能只是因为刺激判断更准确。

为了进一步确定反应偏向和辨别力分别对应哪种决策机制，研究者首先使用层次漂移扩散模型（HDDM）联合拟合每个试次的选择和反应时间。模型将贫刺激反应设为下边界，将富刺激反应设为上边界，并估计漂移率、决策阈值、起始点和非决策时间。如果反应偏向主要与起始点有关，说明个体在刺激证据到来之前已经倾向于选择富刺激反应；如果辨别力主要与漂移率和决策阈值有关，则说明判断准确性同时取决于证据质量和反应谨慎性。因为标准HDDM适合描述已经形成的决策状态，并不能直接解释偏向如何随奖励反馈逐渐形成。研究者进一步采用强化学习漂移扩散模型（RLDDM）和信念模型。RLDDM根据每个试次的奖赏预测误差更新刺激—行动价值，再利用两个反应选项的价值差调节当次试次的漂移率，从而描述奖励经验如何逐步改变证据积累方向。信念模型同样根据反馈更新行动价值，但进一步考虑被试对刺激身份的不确定性，并估计奖赏敏感性、学习率、知觉信念和初始行动偏向等参数。其中，HDDM主要回答“当前的决策偏向由哪些成分构成”，而RLDDM和信念模型更关注“这种偏向如何通过反馈形成”。研究者结合模型拟合、后验预测和参数信度评价不同模型，以判断它们能否准确且稳定地解释任务行为。

实验结果显示，被试总体形成了对富刺激的反应偏向，但任务收益主要取决于刺激辨别力，而非反应偏向的强弱。HDDM进一步表明，反应偏向主要对应起始点向富刺激边界偏移，辨别力则由漂移率和决策阈值共同预测。标准HDDM能够较好地复现准确率、反应时间和辨别力，且参数信度较高，但难以描述反应偏向随区块逐渐增强的过程。RLDDM和信念模型能够表现偏向的动态形成，却在行为拟合或参数稳定性方面存在不足。治疗预测结果总体不稳定，仅初步发现较强的基线起始点偏向可能与后续安非他酮疗效有关，但仍需更大样本和独立研究验证。

通过使用漂移扩散模型和强化学习模型，研究者能够量化被试在概率奖赏任务中的证据积累与价值更新过程，并进一步理解奖赏反馈如何影响后续选择。HDDM帮助研究者区分了决策前的反应偏向、刺激证据的积累效率和作答谨慎程度，而强化学习模型则用于描述这种偏向如何随反馈逐步形成。该研究不仅揭示了抑郁症奖赏加工同时涉及知觉决策与强化学习过程，也展示了计算模型在分解复杂临床行为和探索潜在治疗预测指标方面的应用价值。

**文章代码解读**

研究者使用HDDM工具箱中的RLDDM分析概率奖赏任务数据。该模型首先根据反馈更新不同刺激—行动组合的价值，再将两个反应选项的价值差转换为试次水平的漂移率，从而同时解释奖赏学习、选择结果和反应时间。

接下来我们将以该研究代码文件Placebo\_PRT\_RLDDM.html为例，详细说明如何实现RLDDM的计算过程：

1. 库的导入

```python
import hddm
import numpy as np
import pandas as pd
import scipy as sp
import seaborn as sns
from matplotlib import pyplot as plt
```

* hddm: 建立和估计RLDDM。
* numpy和pandas：进行数值运算与数据整理。
* scipy：完成参数转换和统计计算。
* seaborn和matplotlib：绘制参数分布及后验预测图。

代码还通过以下命令检查HDDM版本：

```python
hddm.__version__
```

2. 设置采样参数

```python
n_samples = 2500
n_burn = 500
```

* n\_samples = 2500表示每条MCMC链抽取2500个样本；
* n\_burn = 500表示舍弃前500个烧入样本，以减少初始值对后验估计的影响。

研究者分别对第一次和第二次测量的数据拟合模型。

3. 加载清洗后的数据

```python
s1_tclean = pd.read_csv(path2asys + 's1_tclean.csv')
s2_tclean = pd.read_csv(path2asys + 's2_tclean.csv')
```

注意这里加载的不是原始数据，而是已经完成反应时异常值排除和任务质量控制的数据。s1\_tclean和s2\_tclean分别对应第一次和第二次测量。

4. 整理RLDDM所需的数据格式

以第一次测量为例：

```python
s1_rlddm = s1_tclean[
    ['subject', 'session', 'block', 'trial',
     'stimulus_type', 'response_type', 'rt', 'reward']
]
```

代码保留以下信息：被试编号、测量时间、任务区块与试次、刺激类型、被试反应、反应时间、奖赏反馈。

随后将变量名转换为HDDM所需的格式：

```python
s1_rlddm.rename(
    columns={
        'subject': 'subj_idx',
        'stimulus_type': 'stim',
        'response_type': 'response',
        'rt': 'rt_orig',
        'reward': 'feedback',
        'trial': 'trial_orig'
    },
    inplace=True
)
```

其中，subj\_idx、response、rt和feedback是RLDDM识别被试、反应、反应时间和反馈信息的关键变量。

5. 设置初始价值并编码刺激与反应

```python
s1_rlddm['q_init'] = 0.5
s1_rlddm['rt'] = s1_rlddm.rt_orig / 1000.00
s1_rlddm.response.replace({'lean': 0, 'rich': 1}, inplace=True)
s1_rlddm['split_by'] = s1_rlddm.stim.apply(
    lambda x: 1 if x == 'rich' else 0
)
```

这几行代码完成了四项处理：

1. q\_init=0.5：把所有刺激—行动组合的初始价值设为0.5，表示模型开始时没有充分的价值信息；
2. 将反应时间由毫秒转换为秒，以符合HDDM的时间尺度；
3. 将贫刺激反应编码为0，富刺激反应编码为1；
4. 使用split\_by标记刺激类型，其中贫刺激为0，富刺激为1。

在这种编码下：

* 下边界0对应贫刺激反应；
* 上边界1对应富刺激反应；
* 当response与split\_by相同时，该试次反应正确。

代码还分别在富、贫刺激条件内重新编号试次，使每个条件的试次从1运行到150。这是为了适应该版本RLDDM对条件序列的输入要求，并不意味着所有RLDDM分析都必须采用相同处理。。

6. RLDDM的核心计算逻辑

RLDDM首先根据奖赏预测误差更新刺激—行动价值。其基本过程可以表示为：

<p align="center"><span class="math">\delta_t=r_t-Q_t(s_t,a_t)</span></p>

<p align="center"><span class="math">Q_{t+1}(s_t,a_t) = Q_t(s_t,a_t)+\alpha\delta_t\</span></p>

其中，δₜ是奖赏预测误差，rₜ是实际反馈，Qₜ是当前价值估计，α是学习率。

随后，模型将两个反应选项的价值差转换为当前试次的漂移率：

$$
v_t=\kappa\left(Q_{t,\mathrm{rich}}-Q_{t,\mathrm{lean}}\right)
$$

其中，κ 是价值差到漂移率的缩放参数。在代码输出中，该参数仍以 v 命名，但其含义不同于标准 HDDM 中固定的平均漂移率：它表示价值差对证据积累速度的影响强度。

因此，代码估计的主要参数包括：

* a：决策阈值；
* t：非决策时间；
* v（或 scaler）：价值差到漂移率的缩放系数；
* α（代码中为 alpha）：强化学习率。

该模型不像前述标准 HDDM 那样单独估计起始点偏向。对富刺激的偏向主要通过学习所得的价值差改变逐试次漂移率而产生。

7. 建立并拟合RLDDM

```python
m = hddm.HDDMrl(s1_rlddm)
m.find_starting_values()
m.sample(
    n_samples,
    burn=n_burn,
    dbname=db_name,
    db='pickle'
)
```

其中：

* hddm.HDDMrl()根据逐试次选择、反应时间和反馈建立RLDDM；
* find\_starting\_values()寻找较合理的参数初始值；
* sample()运行MCMC采样；
* dbname和db='pickle'将每条链的采样结果保存为数据库文件。

研究者分别运行三条独立链：

```python
s1_models = []

for i in range(1, 4):
    m = hddm.HDDMrl(s1_rlddm)
    m.find_starting_values()
    m.sample(n_samples, burn=n_burn,
             dbname=db_name, db='pickle')
    s1_models.append(m)
```

使用多条链可以判断不同初始状态是否收敛到相同的后验分布。

8. 检查模型收敛

```python
hddm.analyze.gelman_rubin(s1_models)
```

代码计算 Gelman–Rubin 指标（R̂），并提取其最大值。结果如下：

* 第一次测量：最大 R̂ = 1.003；
* 第二次测量：最大 R̂ = 1.0282。

两次测量的最大 R̂ 值均低于 1.1，表明三条采样链基本收敛。不过，收敛仅说明采样过程较为稳定，并不能证明模型能够准确复现实验中的实际行为。

9. 合并采样链并保存结果

```python
s1_rlddm_concat = hddm.analyze.utils.concat_models(s1_models)
s1_rlddm_concat.plot_posteriors()

s1_rlddm_concat_traces = s1_rlddm_concat.get_traces()
s1_rlddm_concat_traces.to_csv(
    path2rlddm + 's1_rlddm_concat_traces.csv'
)

s1_rlddm_stats = s1_rlddm_concat.gen_stats()
s1_rlddm_stats.to_csv(
    path2rlddm + 's1_rlddm_concat_stats.csv'
)
```

其中：

* concat\_models()将三条链的后验样本合并；
* get\_traces()提取完整后验样本；
* gen\_stats()生成参数的后验均值、标准差和可信区间等摘要。

由于该版本不能直接保存完整RLDDM对象，代码没有使用普通的model.save()，而是分别保存：每条链的数据库、合并后的后验样本、参数统计摘要、DIC结果。

10. 检查参数相关性和学习率

研究者绘制参数对图，考察 α、t、a 和 v 之间的后验相关性。较弱的后验相关性表明，各参数之间未出现明显的相互补偿，但这并不能单独证明参数具有良好的可辨识性。

学习率 α 通过以下方式进行转换：

```python
alpha = sp.special.expit(alphaInv)
```

采样时的alpha位于无界的实数尺度上，因此使用逻辑函数将其转换到0—1范围：

$$
\alpha=\frac{1}{1+e^{-\alpha_{\mathrm{inv}}}}\
$$

转换后的学习率较低，意味着单次反馈只会小幅改变原有价值估计，价值偏向需要经过多个试次逐渐形成。

11. 使用DIC比较模型

```python
s1_rlddm_concat.dic
```

DIC越低，表示模型在拟合程度和复杂度之间的综合表现越好。两次测量中，标准HDDM的DIC均低于RLDDM，说明加入强化学习过程后，模型并未获得更好的整体拟合。

12. 后验预测

研究者从合并后的后验样本中随机抽取参数，为每名被试生成50套模拟数据：

```python
a = traces.loc[sample, 'a_subj.' + str(subj)]
t = traces.loc[sample, 't_subj.' + str(subj)]
scaler = traces.loc[sample, 'v_subj.' + str(subj)]
alphaInv = traces.loc[sample, 'alpha_subj.' + str(subj)]
alpha = sp.special.expit(alphaInv)
```

随后分别模拟贫刺激和富刺激：

```python
sim_lean = hddm.generate.gen_rand_rlddm_data(
    a=a,
    t=t,
    scaler=scaler,
    alpha=alpha,
    size=150,
    p_upper=0.0,
    p_lower=0.2,
    split_by=0
)

sim_rich = hddm.generate.gen_rand_rlddm_data(
    a=a,
    t=t,
    scaler=scaler,
    alpha=alpha,
    size=150,
    p_upper=0.6,
    p_lower=0.0,
    split_by=1
)
```

其中：

* size=150表示分别模拟150个富刺激和150个贫刺激试次；
* 富刺激正确反应对应上边界，奖励概率设为0.6；
* 贫刺激正确反应对应下边界，奖励概率设为0.2。

这与每个区块中富刺激最多30次奖励、贫刺激最多10次奖励的3∶1强化安排相对应。

模拟完成后，代码计算正确率、反应时间、反应偏向和辨别力，并与观察数据比较。结果显示，RLDDM能够产生随区块增强的反应偏向，但低估了正确率和辨别力；模拟的第一区块还出现了观察数据中不存在的负向偏向。因此，模型捕捉到了学习趋势，却没有充分复现知觉决策表现。。

# 3.6 拓展阅读：p值的物理意义

讲完了概率推断的基础知识，我们不妨回顾一下心理统计中常见的一个问题，就是在统计中$$p$$值的具体定义。虽然很多学生在学习心理统计之后，都可以手动算出例如一个简单t检验的t值和查找对应$$p$$值。但是从概率上讲，任何的概率值都会对应一个物理意义。那么心理统计中常见的$$p$$值的物理意义是什么呢？也许很多同学并没有思考过这个题。著名期刊Nature曾经多次发文讨论在研究过程中对$$p$$值的错误理解或者是误用<sup>⁠4⁠,⁠5</sup>。



我在下面开脑洞，随便想了一个简单的统计题。

{% hint style="danger" %}
### <mark style="color:red;">**思考题**</mark>

为了比较某校学生2025年和2024年的饭量差异，我们分别测量了一些学生各自在两年的饭量平均值，并将此数据集记为 $$data$$.

那么，根据心理统计的原理，我们可以构成零假设和备择假设

$$H_0$$: 2025年和2024年的饭量没有显著差异

$$H_1$$: 2025年和2024年的饭量有显著差异<br>

然后你做了一个简单t检验，计算出了p值，请问这个$$p$$值的物理意义? 我提供下面一系列的选项

1. $$H_0$$为真的概率, 即$$p(H_0= True)$$
2. $$H_1$$为真的概率, 即$$p(H_1=True)$$
3. 基于当前数据，$$H_0$$为真的概率，即$$p(H_0=True | data)$$
4. 基于当前数据，$$H_1$$为真的概率，即$$p(H_1= True | data)$$
5. 如果$$H_0$$为真，观察到$$\text data$$当前数据的概率，即$$p(data | H_0= True)$$
6. 如果$$H_1$$为真，观察到当前数据的概率，即$$p( data | H_1= True)$$
7. 如果$$H_0$$为真，观察到当前数据甚至更极端的数据的概率，即$$p( data或者更极端 | H_0= True)$$
8. 如果$$H_1$$为真，观察到data甚至更极端的数据的概率，即$$p( data或者更极端 | H_1= True)$$
{% endhint %}

因为我们这一章节学习了概率推断和条件概率等概念，那么上面的这些概率表达，你肯定能理解什么意思。

不知道你能否算出来，正确答案是: 7

在假设检验中，我们认为数据可能是在两种原因下产生的，一是$$H_0$$，二是$$H_1$$。在$$t$$检验中，我们假设$$H_0$$为真，$$p$$值代表的含义是观察到当前数据以及更极端数据的可能性。因此，如果我们使用条件概率的方式来看待熟悉的假设检验，正确的表示为：$$p = p( data或者更极端 | H_0= True)$$

{% hint style="danger" %}
### <mark style="color:red;">**进一步思考**</mark>

1. $$p( data或者更极端| H_0=True) + p(data或者更极端| H_1= True) = 1$$ 一定成立吗？
2. 有没有可能 $$p( data或者更极端 | H_1= True) < p(  data或者更极端 | H_0= True)$$?
{% endhint %}

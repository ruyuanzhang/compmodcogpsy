# Appendix

## 本章数学符号总结

| 符号                              | 含义                          |
| ------------------------------- | --------------------------- |
| $$N$$                           | 实验的总次数；数据点的数量               |
| $$A$$、$$B$$                     | 事件                          |
| $$k$$                           | 事件发生的次数                     |
| $$p(A)$$                        | 事件 $$A$$ 的概率                |
| $$X$$、$$Y$$                     | 随机变量                        |
| $$x$$、$$y$$                     | 随机变量的取值                     |
| $$\xi$$                         | 样本空间                        |
| $$e$$                           | 简单事件                        |
| $$p(A, B)$$                     | 联合概率                        |
| $$p(A \mid B)$$                 | 条件概率                        |
| $$x_i$$                         | 离散随机变量的第 $$i$$ 个取值          |
| $$p_i$$                         | 取第 $$i$$ 个值的概率              |
| $$f(x)$$                        | 概率密度函数                      |
| $$F(x)$$                        | 累积分布函数                      |
| $$[a, b]$$                      | 区间                          |
| $$\mu$$                         | 均值                          |
| $$\sigma$$                      | 标准差                         |
| $$\theta$$                      | 分布的参数                       |
| $$n$$                           | 伯努利实验的次数                    |
| $$\alpha$$、$$\beta$$            | Beta 分布的形状参数                |
| $$\mathrm{B}(\alpha, \beta)$$   | Beta 函数                     |
| $$E(X)$$                        | 期望                          |
| $$\mathrm{Var}(X)$$             | 方差                          |
| $$O$$                           | 观察数据                        |
| $$C$$                           | 原因                          |
| $$p(O \mid C)$$                 | 条件概率分布                      |
| $$L(\theta)$$                   | 似然函数                        |
| $$D$$                           | 数据集                         |
| $$d_i$$                         | 第 $$i$$ 个数据点                |
| $$\mathcal{N}(\mu, \sigma^2)$$  | 正态分布                        |
| $$\mathrm{LL}(\theta)$$         | 对数似然函数                      |
| $$\mathrm{NLL}(\theta)$$        | 负对数似然函数                     |
| $$\hat{\theta}$$                | 参数的估计值                      |
| $$\hat{\theta}_{\mathrm{MLE}}$$ | 最大似然估计值                     |
| $$\arg\max$$、$$\arg\min$$       | 使函数取得最大值、最小值的参数             |
| $$a$$、$$b$$                     | 线性模型的斜率、截距                  |
| $$\epsilon$$                    | 误差项                         |
| $$\mu_i$$                       | 第 $$i$$ 个数据点的均值             |
| $$p(\theta)$$                   | 先验分布                        |
| $$p(D \mid \theta)$$            | 似然函数                        |
| $$p(D)$$                        | 数据的边缘概率                     |
| $$p(\theta \mid D)$$            | 后验分布                        |
| $$\propto$$                     | 成比例                         |
| $$\hat{\theta}_{\mathrm{MAP}}$$ | 最大后验估计值                     |
| $$H_0$$、$$H_1$$                 | 零假设、备择假设                    |
| $$p$$ 值                         | $$H_0$$ 为真时观察到当前数据或更极端数据的概率 |

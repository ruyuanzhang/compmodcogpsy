# 8.5 强化学习变种和模型比较

上一个章节，我们介绍了如果利用基本的强化学习模型去你和一个概率反转实验的真实实验数据。在计算建模的过程中，我们经常会同时提出多个可能的模型，这些模型可能基于不同的理论假设，而分别用这些模型来拟合同样的数据来看哪个模型更好的解释数据，是一种常见的区分不同计算理论的方式。这一节，我们基于前一节介绍的经典强化学习模型，并介绍两个强化学习模型的变种，来示例如何做模型比较。

## 生成数据

我们首相用经典强化学习来生成数据，沿用上一节的思路

{% code overflow="wrap" %}
```python
import numpy as np
from scipy.stats import bernoulli
p = 0.7 # reward probability
T = 1000

Va, Vb, choice, reward = np.empty(T+1), np.empty(T+1), np.empty(T), np.empty(T)
Va[0], Vb[0] = 0.5, 0.5 # 对A和B的初始价值都是0.5
alpha = 0.02 # learning rate
beta = 1 # inverse temperature
for i in range(T): #注意这里是
    
    # 我们用logstic函数来生成选择A的概率并且做出选择
    pa = 1/(1+np.exp(-beta*(Va[i]-Vb[i])))
    choice[i] = bernoulli.rvs(pa) # 选A为1，选B为0

    # 根据被试的选择来给与奖赏
    if i <= T/2: # 前半实验
        reward[i] = bernoulli.rvs(p) if choice[i]==1 else bernoulli.rvs(1-p)
    else: # 后半实验
        reward[i] = bernoulli.rvs(1-p) if choice[i]==1 else bernoulli.rvs(p)

    # 被试根据reward，按照强化学习的逻辑更新
    if choice[i] == 1: # choose A
        # update Va
        Va[i+1] = Va[i] + alpha * (reward[i] - Va[i])
        # normalize Va and Vb such that Va+Vb=1
        #Va[i+1], Vb[i+1] = Va[i+1]/(Va[i+1]+Vb[i]), Vb[i]/(Va[i+1]+Vb[i])
        Vb[i+1] = 1- Va[i+1]    
    else: # choose B
        # update Vb
        Vb[i+1] = Vb[i] + alpha * (reward[i] - Vb[i])
        # normalize Va and Vb such that Va+Vb=1
        #Va[i+1], Vb[i+1] = Va[i]/(Va[i]+Vb[i+1]), Vb[i+1]/(Va[i]+Vb[i+1])    
        Va[i+1] = 1- Vb[i+1]
```

## 比较三种强化学习模型

### **经典强化学习模型**

首先，我们按照上一节讲的，针对经典强化学习模型的更新公式，来构建计算人的行为的负对数似然的函数。

$$
V_{c,t+1}=V_{c,t}+\alpha*(r_t-V_{c,t})
$$

来构建计算人的行为负对数似然的函数。

{% code overflow="wrap" %}
```python
def nll_rl(params):
    alpha = params[0] # learning rate
    beta = params[1] # inverse temperature

    Va, Vb, pp = np.empty(T+1),np.empty(T+1),np.empty(T)
    Va[0], Vb[0] = 0.5, 0.5 
    for i in range(T): # loop trial
        # 获得这个trial被试做出这个选择的概率
        pa = 1/(1+np.exp(-beta*(Va[i]-Vb[i]))) #选择A的概率
        pp[i] = pa if choice[i]==1 else 1-pa
        
        # update value
        if choice[i] == 1: # choose A
            # update Va
            Va[i+1] = Va[i] + alpha * (reward[i] - Va[i])
            # normalize Va and Vb such that Va+Vb=1
            Vb[i+1] = 1- Va[i+1]    
        else: # choose B
            # update Vb
            Vb[i+1] = Vb[i] + alpha * (reward[i] - Vb[i])
            # normalize Va and Vb such that Va+Vb=1
            Va[i+1] = 1- Vb[i+1]
    
    pp = 0.999 * pp + np.finfo(np.float32).eps # 防止为0
    return -np.log(pp).sum()
```

### **反事实更新模型（Counterfactual Update Model）**

**Counterfactual Update Model** 强调的是在学习过程中，不仅考虑实际发生的结果，还考虑那些未被选择的动作的潜在结果（反事实，counterfactual outcomes）。这一模型通常用于对比实际行为与可能的行为，从中学习更加优质的策略。

在实验中，该模型不仅更新这个试次已选择选项的价值：

$$
V_{c,t+1}=V_{c,t}+\alpha*(r_t-V_{c,t})
$$

还更新这个试次未被选择选项的价值：

$$
V_{nc,t+1}=V_{nc,t}+\alpha*(-r_t-V_{nc,t})
$$

其中 $$V_{c,t}$$ 和 $$V_{nc,t}$$ 分别是该试次内选择选项和未选择选项的价值。

{% code overflow="wrap" %}
```python
def nll_cfu(params):
    alpha = params[0] # learning rate
    beta = params[1] # inverse temperature

    Va, Vb, pp = np.empty(T+1),np.empty(T+1),np.empty(T)
    Va[0], Vb[0] = 0.5, 0.5 
    for i in range(T): # loop trial
        # 获得这个trial被试做出这个选择的概率
        pa = 1/(1+np.exp(-beta*(Va[i]-Vb[i]))) #选择A的概率
        pp[i] = pa if choice[i]==1 else 1-pa
        
        # update value
        if choice[i] == 1: # choose A，注意这里两个选项的价值都要更新
            # update Va
            Va[i+1] = Va[i] + alpha * (reward[i] - Va[i])
            # also update Vb
            Vb[i+1] = Vb[i] + alpha * (-reward[i] - Vb[i])            

        else: # choose B，注意这里两个选项的价值都要更新
            # update Vb
            Vb[i+1] = Vb[i] + alpha * (reward[i] - Vb[i])
            # update Va
            Va[i+1] = Va[i] + alpha * (-reward[i] - Va[i])

        # normalize such that Va + Vb = 1
        Va[i+1], Vb[i+1] = Va[i+1]/(Va[i+1]+Vb[i+1]), Vb[i+1]/(Va[i+1]+Vb[i+1])
    
    pp = 0.999 * pp + np.finfo(np.float32).eps # 防止为0
    return -np.log(pp).sum()
```

### **奖励-惩罚模型（Reward-Punishment Model）**

**Reward-Punishment Model** 是一种通过强化和抑制行为的方式来学习策略的模型。它根据正向反馈（奖励）和负向反馈（惩罚）来调整代理的行为。这种模型与行为主义心理学中的强化理论（reinforcement theory）紧密相关。当Agent在环境中采取某个动作并获得奖励时，该动作的倾向性会增强（正强化）；相反，如果代理因为某个动作受到了惩罚，执行该动作的倾向性就会减弱（负强化或惩罚）。Reward-Punishment Model 假定Agent的目标是最大化奖励并最小化惩罚，因此它通过调整行为的概率来促使代理趋向于那些带来正向反馈的行为，而避免负向反馈的行为。

在实验中，如果这个试次获得了奖赏，用一个学习率 $$\alpha^{rwd}$$：

$$
V_{c,t+1}=V_{c,t}+\alpha^{rwd}*(r_t-V_{c,t})
$$

如果这个试次没有获得奖赏（这里等价于惩罚），用另一个学习率 $$\alpha^{pun}$$：

$$
V_{c,t+1}=V_{c,t}+\alpha^{pun}*(r_t-V_{c,t})
$$

我们同样构建奖励-惩罚模型的负对数自然函数

```python
def nll_rp(params):
    alpha = params[0] # reward learning rate
    alpha1 = params[1] # punishment learning rate
    beta = params[2] # inverse temperature

    Va, Vb, pp = np.empty(T+1),np.empty(T+1),np.empty(T)
    Va[0], Vb[0] = 0.5, 0.5 
    for i in range(T): # loop trial
        # 获得这个trial被试做出这个选择的概率
        pa = 1/(1+np.exp(-beta*(Va[i]-Vb[i]))) #选择A的概率
        pp[i] = pa if choice[i]==1 else 1-pa
        
        # update value
        if choice[i] == 1: # choose A
            # update Va
            if reward[i] == 1: # reward
                Va[i+1] = Va[i] + alpha * (reward[i] - Va[i])
            else:
                Va[i+1] = Va[i] + alpha1 * (reward[i] - Va[i])
                
        else: # choose B
            # update Vb
            if reward[i] == 1: # reward
                Vb[i+1] = Vb[i] + alpha * (reward[i] - Vb[i])
            else:
                Vb[i+1] = Vb[i] + alpha1 * (reward[i] - Vb[i])

    pp = 0.999 * pp + np.finfo(np.float32).eps # 防止为0
    return -np.log(pp).sum()
```

## 模型比较

当多个模型存在时，需要进行模型比较来探索其中的最佳模型。模型比较过程涉及模型拟合优度(goodness of fit)和模型复杂度之间的权衡。常见的两个模型评估指标有AIC（Akaike Information Criterion）和BIC（Bayesian Information Criterion）。这两个指标通过交叉验证(Cross validation)以及近似交叉验证的方法来验证模型的泛化能力(Generalization ability)，即基于当前样本数据拟合后的模型对于样本外数据预测准确度(Out of sample prediction accuracy)。计算过程中为了平衡模型的拟合优度和复杂度，防止过拟合, AIC 和BIC均引入了惩罚项。

### **AIC**

AIC(Akaike information criterion)是最早被提出的用于模型比较的指标之一(Akaike, 1974)。它度量了模型所预测的数据分布与真实数据分布之间的差异，且已被证明是样本外预测能力（Out-of-sample predictive accuracy）和留一法交叉验证（LOO-CV）的近似（Stone, 1977）。AIC的计算公式为：

$$
AIC = −2log(p(data|𝜃)) + 2∗k
$$

其中，$$log(p(data|\theta))$$为极大似然法估计得到的最优参数$$\theta$$的对数似然函数值，用于评估模型拟合优度；$$k$$为自由参数的数量，用于对模型复杂度的惩罚。随着$$k$$的增加，对模型的惩罚也会增加。AIC 的值越小，表明模型的拟合效果越好。关于AIC差异的解释，Burnham和Anderson（2004）建议，当两个模型的AIC之差的绝对值小于2时，可以认为两个模型之间几乎无差异；当该值在4到7之间时，存在一定证据支持AIC值较小的模型；当该值大于10时，有充分证据认为AIC较小的模型是优于其他模型的。此外，AIC渐近于卡方分布（Anderson & Burnham, 2004），因此研究者可以使用卡方检验对比不同模型的AIC值是否存在显著差异。但是这里的AIC的值，受到数据数量的影响，数据数量越大，一般来说AIC绝对值越大。

### **BIC**

BIC（贝叶斯信息准则，Bayesian Information Criterion）与AIC相似，是最经典且应用最广泛的模型选择指标之一（Schwarz, 1978）。BIC可视为拉普拉斯近似（Laplace approximation）边际似然的一个特例（Bishop, 2006）。在计算拉普拉斯近似时，假设先验分布为无信息先验，并且当数据点数量𝑛极多时，根据大数定律，拉普拉斯近似的结果可简化为BIC。BIC的计算公式为：

$$
𝐵𝐼𝐶 = −2log (p(data|\theta)) + k*log(n)
$$

其中，和AIC不同的项 $$k*log(n)$$是对模型复杂度的惩罚项，$$k$$是参数数量，$$𝑛$$是数据数量。BIC不仅考虑了参数数量对模型复杂度的影响，还将数据量纳入模型复杂度惩罚的关键因素。与AIC相似，BIC的值越小，表明模型拟合效果越好。

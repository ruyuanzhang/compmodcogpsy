# 8.2 心理学的强化学习

在从机器学习的角度讲完了强化学习之后，我们不妨重新换个视角，从认知心理学的角度重新审视强化学习。在这一章中，我们刻意把机器学习里面的强化学习和认知心理学里面的强化学习作为两条平行线来介绍，在章节8.3中我们会把两条线交汇介绍两者之间的关系。

## 心理学史上四种著名的动物

现代实验心理学的形成通常以冯特（Wilhelm Wundt）于 1879 年在莱比锡建立实验心理学实验室为重要标志。与此同时，动物学习研究逐渐发展出一条解释经验如何改变行为的重要路径。我们不妨先回顾一下心理学史上的四大“神兽”：巴普洛夫的狗(Pavlov's dog)，桑代克的猫(Thorndike's cat)，科勒的黑猩猩(Kohler’s chimpanzee)，还有斯金纳的老鼠(Skinner’s mouse)。

### 巴甫洛夫的狗

动物无需学习，就会因食物而分泌唾液。其中，食物被称为无条件刺激（unconditioned stimulus），食物诱发的唾液分泌被称为无条件反应（unconditioned response）。但是俄国生理学家巴甫洛夫注意到，除了食物之外，狗还会对着喂他们的人分泌口水。为了实验验证这一观察，他在喂食狗之前先给予一个中性刺激，如响铃或亮灯。在重复多次之后，仅提供这些中性刺激就可以诱发狗分泌口水。这一将无条件刺激与中性刺激联系起来的学习过程被称为经典条件反射(classic conditioning）。

### 桑代克的猫

美国心理学家桑代克把饥饿的猫放在带闩的木箱里，这个木箱的门可以通过移动闩来打开，猫如果成功打开门就可以获取箱外的食物。一开始，猫只会发出焦虑的叫声并随即抓箱子，最后会偶然撞上门闩成功获得食物。经过反复试验，猫会学会更快地操作锁扣，以逃离盒子并到达食物。桑代克测量了猫在每次试验中逃离盒子所需的时间，并绘制了一条学习曲线，在该曲线中，逃脱时间随着连续试验而减少。桑代克将这一过程视为通过尝试与错误逐渐学习有效行为的过程，因此通常称为试误学习（trial-and-error learning）。桑代克同时提出了效果律（law of effect），即得到满意效果的行为重复出现的概率会上升，得到不满意效果的行为重复出现的几率会下降。

### 科勒的黑猩猩

德国格式塔心理学家科勒为黑猩猩设计了一系列更加复杂的任务，例如将食物扔到窗外，并关上窗户，黑猩猩能够很快以最短路径找到消失的食物。因而科勒认为动物学习过程并非单纯的试错，也有对事物的深入理解参与其中，这种学习方式称之为顿悟式学习（insight learning）。

### 斯金纳的老鼠

在桑代克的基础上，斯金纳设计了操作性条件反射室（斯金纳箱）来研究老鼠的学习行为。老鼠可以通过按压操作杆获得食物，或通过特定反应终止厌恶刺激（如噪声），实验过程中动物会强化能获得奖赏的行为，减少得不到奖赏的行为。因而斯金纳提出了操作性条件反射（operant conditioning），也称工具性条件反射（instrumental conditioning）。在工具性条件反射的学习过程中，动物的自主行为受到由该行为带来的奖励或惩罚的调控，其频率会因为强化而增加，因为惩罚而减少。

<figure><img src="../.gitbook/assets/image (86).png" alt="" width="260"><figcaption><p>图8-21 斯金纳箱与操作性条件作用</p></figcaption></figure>

经典条件反射与工具性条件反射代表了两种不同的学习模式，经典条件反射是通过无条件刺激与中性刺激的配对形成的非自愿的、机体自动发生的学习过程；而工具性条件反射是动物自愿行动的结果反过来强化其特定行为的学习模式。工具性条件作用强调行为的结果会影响该行为未来发生的概率，这一思想也启发了强化学习中的价值更新与行为选择模型。

这些经典研究从不同角度揭示了经验与学习如何改变行为。其中，桑代克的效果律和斯金纳的操作性条件作用尤其强调行为结果对后续选择的影响；巴甫洛夫的条件作用则展示了对奖赏的预测如何通过学习形成。接下来，我们将把其中“通过反馈调整行为”的思想转化为一个可计算的问题：个体如何从不确定的奖赏结果中估计选项的价值？

## 单臂老虎机问题

在斯金纳箱中，老鼠每按下一个按钮就能获得对应的奖赏或惩罚，而在自然界中，决定与奖赏的对应关系是并不明确的，某个决策并不能每次都能获得奖赏，如是否采取捕猎行为或是否投资某一个项目。在这种情形下，生物要如何学习使得奖赏最大化呢？

<figure><img src="../.gitbook/assets/image (87).png" alt="" width="200"><figcaption><p>图8-22 单臂老虎机示意图</p></figcaption></figure>

老虎机即是一个最简单的例子，玩家投币之后拉动侧面的拉杆，内部的三个转轴就会带动前方的图案旋转，最后出现三个相同的图案时就可以获得奖金。

我们假设玩家可以向左或向右拉动拉杆，即这台老虎机有左右两个选项。假设选择左边选项获得奖励的概率是$$p$$，则选择右边选项获得奖励的概率是$$1-p$$。进一步地，我们可以将某个选项可能带来的奖赏期望定义为该选项的价值(value)。

{% hint style="info" %}
注意，这里我们从心理学的角度定义了价值，可以思考一下这里的定义和前面章节机器学习里面强化学习关于价值的定义有何不同。
{% endhint %}

如果每次老虎机给出的奖励数量是固定的，每一个选项的价值就可以简单等同于获得奖励的概率。知觉上看某一选项获得奖励的概率越大，价值越高。在这样一个赌博试验中，受试并不知道这一概率的设定，因此需要不断地试错来学习这一奖赏概率。显然，最简单的一种方法是尝试很多次同一选项，然后求选择该选项多次的平均奖赏。为了模拟这一学习过程，我们假设受试每次都选择左边，因为试验结果是二元的，故可以用伯努利分布模拟被试每次获得的奖励。

```python
import numpy as np
from scipy.stats import bernoulli
p = 0.6 # 人为设定奖赏概率（reward probability）
T = 1000 # 尝试1000次

# 模拟T个试次中被试获得的奖赏
reward = bernoulli.rvs(p, size=T)
print(reward[:10]) # 我们展示前10次选择的结果
```

这里前10次的选择左边选项的结果，0代表没有获得奖赏，1代表获得了奖赏。

受试每选择一次，可以把之前的$$t$$次奖赏进行平均来估计其价值，由此可以画出受试随着试次数增加，对左边选项的价值的估计。

```python
import matplotlib.pyplot as plt
v = np.empty(T)
for i in range(T): # 为每个试次执行循环操作
    if i == 0: 
        v[i] = reward[0]
    else:
        v[i] = reward[:i+1].mean()# 对之前i个试次中的奖赏求平均

plt.plot(v, '-o')
plt.axhline(p, color='r')
plt.xlabel('Trials')
plt.ylabel('Value')
plt.ylim([0, 1])
```

<figure><img src="../.gitbook/assets/image (72).png" alt="" width="315"><figcaption><p>图8-23 利用历史平均法估计选项奖励价值的学习曲线</p></figcaption></figure>

我们可以看到随着试次数增加，受试对左边选项的价值的估计会逐渐收敛到其真实值，这是一个很简单的历史平均法。但是历史平均法要求受试在“内存”里面记录下之前所有试次的奖赏值，人脑容量是有限的，因此这是一种非常不经济的方法，有没有其他方法可以**更经济**地实现对某一选项价值的估计呢？

首先观察一下历史平均法，在第$$t$$个试次，之前所有$$t$$个奖赏值$$r$$的平均值即为该选项的价值的估计值 $$V_t$$，可以表示为：

$$
V_t=\frac{1}{t} (r_1 + r_2 + ... + r_{t-1} + r_t)   \qquad (8-24)
$$

我们可以得出 $$t-1$$的试次时价值的估计值：

$$
V_{t-1}=\frac{1}{t-1} (r_1 + r_2 + ... + r_{t-1}) \qquad (8-25)
$$

因此联立以上两个公式，我们可以得出$$V_t$$ 是基于 $$V_{t-1}$$进行更新的：

$$
V_t=\frac{1}{t}\left[(t-1)V_{t-1}+r_t\right]\\
=V_{t-1}+\frac{1}{t}(r_t-V_{t-1}) \qquad (8-26)
$$

这就是强化学习的递推公式，该式子中有几个关键的要素：

* $$V_t$$ 和 $$V_{t-1}$$分别是 $$t$$时刻与前一时刻（ $$t-1$$）某一选项的估计**价值**（value）
* &#x20;$$r_t - V_{t-1}$$表示前一时刻的对该选项价值(获得奖赏的期望)与该试次实际获得奖赏之间的差距，因而可以定义为**预测误差**；&#x20;
* $$\frac{1}{t}$$ 表示这一预测误差以一定的比例贡献于估计价值的更新，因此定义为**学习率**（learning rate）。

了解了这三个关键要素之后，式子（3）可以解释为，$$t$$ 时刻对某一选项的估计价值 $$V_t$$ 是在前一时刻估计价值的基础上，以一定的学习率，更新一部分的预测误差。这样受试者就不必记住之前所有试次的奖赏值，而只需要记住上一个试次时对价值的估计值就可以了，这样就大大地释放了他的“内存压力”。

## 概率反转学习

历史平均法虽然可以通过递推公式计算，但它在环境发生变化时仍存在局限。在历史平均法中，学习率 $$\frac{1}{t}$$ 是随着试次数量增加而逐渐减小的，因此可以预见当试次数特别大的时候，学习率将趋近于0，价值也就几乎不更新了。这个时候一旦我们将两个选项的奖赏概率进行调整，受试对真实值的估计将收敛得非常慢，因此缺乏灵活性，难以适应新环境，这就是所谓的概率反转学习（probabilistic reversal learning）。

概率反转学习（probabilistic reversal learning）正是利用这种环境变化来研究个体如何调整选择的一种常见实验范式。以前面的双选项任务为例，假设最初左边选项的奖赏概率为 0.6，右边为 0.4；在完成 1000 个试次之后，两者的奖赏概率反转为 0.4 和 0.6。参与者并不知道反转何时发生，需要持续根据反馈判断哪个选项更有价值。如果仍然采用历史平均法，随着试次数量增加，价值更新会越来越缓慢，因而可能难以快速适应反转后的环境。

这一问题的关键在于历史平均法的学习率是随着试次增加而逐渐减小的，这显著限制了学习的灵活性，因此我们可以将学习率固定下来(下面的例子学习率为0.02)，这种学习过程叫做固定学习率的方法。

为了使模型在反转发生后仍然能够根据新反馈持续调整价值，我们可以将学习率固定为一个常数$$a$$ ，得到以下更新公式：

$$
V_t=V_{t-1}+a*(r_t - V_{t-1})\qquad (8-27)
$$

其中， $$V_{t-1}$$ 是更新前的**价值估计** ， $$r_t - V_{t-1}$$ 是当前试次的**预测误差，** $$a$$ 表示**学习率**（learning rate），决定预测误差对价值更新的影响程度。这个公式与前面历史平均法的递推式（8-26）具有相同的更新结构，区别在于历史平均法采用随试次减小的学习率 $$\frac{1}{t}$$ ，而这里采用固定学习率。

下面通过模拟比较这两种方法对奖赏概率变化的适应。为了突出价值更新的差异，我们先假设参与者始终选择左边选项，观察其对左边选项奖赏概率的估计；第一阶段该选项的奖赏概率为 0.6，第二阶段降为 0.4。

```python
T1 = 1000 # 第一个阶段的试次数
p1 = 0.6 # 第一个阶段选左的奖赏概率
T2 = 1000 # 第二个阶段的试次数
p2 = 0.4 # 第二个阶段选左的奖赏概率
a = 0.02 # 学习率

reward1 = bernoulli.rvs(p1, size=T1) # 第一个阶段选择结果
reward2 = bernoulli.rvs(p2, size=T2) # 第二个阶段选择结果
reward = np.hstack((reward1, reward2))

v_fix = np.empty(T1+T2)
v_avg = np.empty(T1+T2)

for i in range(T1+T2):
    if i == 0: # 第一个试次，没有reward, 认为其概率为0.5
        v_avg[i] = 0.5
        v_fix[i] = 0.5 + a * (reward[i] - 0.5)
    else:
        # 历史平均法
        v_avg[i] = v_avg[i-1] + 1/(i+1) * (reward[i]-v_avg[i-1])
        # 固定学习率
        v_fix[i] = v_fix[i-1] + a * (reward[i]-v_fix[i-1])

plt.figure(figsize=(4,4))
plt.plot(range(T1+T2), v_avg, '--')

plt.hlines(p1, 0, T1, color='m')
plt.hlines(p2, T1, T1+T2, color='m')
plt.vlines(T1, p1, p2, color='m')

plt.legend()
plt.xlabel('Trials')
plt.ylabel('Value')
```

<figure><img src="../.gitbook/assets/image (181).png" alt=""><figcaption><p>图8-24 比较历史平均法和固定学习率的模拟结果</p></figcaption></figure>

从模拟结果可以看到，历史平均法在环境稳定时可以逐渐逼近奖赏概率，但在试次积累较多后，对概率反转的反应较慢。固定学习率模型则能够在反转发生后持续根据新反馈调整价值估计。不过，固定学习率也使模型在稳定环境中更容易受到近期随机反馈的影响。因此，两种方法之间的重要区别不是谁需要保存更多历史奖赏，而是如何在估计稳定性与适应变化的速度之间进行权衡。

## 强化学习的神经基础

在上一节中，我们推导得出了心理学中强化学习的公式（8-27），这个公式几乎是目前几千篇论文背后的数学基础。近些年来，强化学习的神经机制一直是研究的热点，我们现在以强化学习作为例子，介绍一下，算法层面的结论如何和神经活动联系起来。

这里我们问一个基本的问题，我们的大脑真的执行了上面的强化学习更新公式么？有一个基本的预测，如果真的是这样，那么我们的大脑内部应该编码了选项的价值$$V_t$$、奖赏$$r$$、和预测误差$$r-V_{t-1}$$。强化学习领域几位著名的学者Wolfram Schultz，Peter Dayan和P. Read Montague1997年在Science杂志发表了一项著名的研究，为大脑表征这些强化学习元素提供了重要证据。

### 多巴胺能神经元编码预测误差

大量的前人研究结果表明，给予奖赏的时候，多巴胺神经元会有强烈的活动。长期以来，学界普遍认为多巴胺神经元编码的是奖赏。但是Schultz、Dayan 和 Montague（1997）将猴子多巴胺神经元的经典电生理发现与时间差分学习理论联系起来。我们可以结合其中展示的三种典型实验情形理解这一观点。。

第一个实验，他们在猴子上直接供给果汁（奖赏），前面没有出现任何的刺激。当给予奖赏的时候，猴子的多巴胺神经元出现了明确的反应。

第二个实验，研究者重复了巴普洛夫的经典条件反射实验，让猴子先看一张图片，然后在固定的时间间隔(例如500ms)之后给予奖赏。经过多次的条件反射实验，猴子把图片和奖赏联系起来，仅仅出现图片刺激，尚未直接给与奖赏，猴子的多巴胺神经元就会强烈的反应。而到真正给与奖赏的时候，多巴胺反而没有显著的活动。

第三个实验，当猴子已经建立了图片-奖赏的联结之后，呈现图片之后，撤掉了本应出现的奖赏，发现猴子的多巴胺神经元被抑制得比基线水平更低。

{% hint style="info" icon="question" %}
思考: 以上实验结果说明多巴胺神经元编码的是奖赏么？
{% endhint %}

<figure><img src="../.gitbook/assets/image (91).png" alt="" width="375"><figcaption><p>图8-25 多巴胺神经元对奖励预测误差的反应</p></figcaption></figure>

以上的结果表明，多巴胺神经元可能编码的不是奖赏本身($$r$$)，而是预期奖赏和实际奖赏之间的差值，即预期误差(prediction error).

* 在未建立图片-奖赏的条件反射联结的阶段，相当于没有条件刺激（CS，conditioned, reward-predicting stimulus，即图片刺激）而直接给予奖赏（R, primary reward），奖赏 $$r_t$$ 大于预测 $$V_{t-1}$$，因而 $$r_t - V_{t-1}$$是一个正向的预测误差（positive error in prediction of reward），记录到了多巴胺神经元更加活跃的发放模式。
* 在已经建立图片—奖赏的条件关联之后，条件刺激本身就会引发多巴胺神经元的较强反应，而预期中的奖赏到来时不再引发同样强烈的反应，因为神经元对奖赏有了预期，因而预测误差 $$r_t - V_{t-1}$$ 为0.
* 此时如果只给一个条件刺激，而不给后续的奖赏，在本来应该获得奖赏的时刻观察到了多巴胺神经元被显著抑制，与之对应，此时奖赏$$r_t$$为0，预测误差 $$r_t - V_{t-1}$$是负向的。

这一系列结果表明，多巴胺神经元并不是单纯地编码奖赏的信息，而是与预测误差有关，而且预测误差有正负（或者“好坏”）之分。

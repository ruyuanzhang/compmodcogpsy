# 5.1.1 蒙特卡洛

## 总体目标

如果学习了前两章的朋友就会知道，我们总体的目标是通过数据（data or observation）来推断背后的成因（cause or parameter），即我们的目标是求关于参数 $$\theta$$ 的概率分布 $$p(\theta | data)$$。我们根据贝叶斯定理，当然可以有

$$
p(\theta| data) = \frac{p(data|\theta)p(\theta) }{p(data)}
 \qquad\qquad\tag{5-1}
$$

如果 $$p(data|\theta)$$、$$p(\theta)$$ 和 $$p(data)$$ 的结构很复杂，那么求 $$p(\theta | data)$$ 就很复杂了，尤其是其中涉及积分的结构。



那么，不能直接求 $$p(\theta | data)$$，我们能否采取从中采样近似的方式来画出这个分布呢？这就是蒙特卡洛采样的思想。

## 什么是蒙特卡洛？

蒙特卡洛（Monte Carlo）是一种思想或一类方法，它通过随机采样来估计数学问题的数值解，本质上是通过**大量采样来暴力解决问题**，特别适用于复杂的积分、概率计算和优化问题等。

{% hint style="info" %}
例子：如何利用蒙特卡洛方法估计圆周率$$\pi$$？

1. 问题描述：在一个边长为 2 的正方形中，内嵌一个半径为 1 的圆，我们希望估计圆的面积。
2. 生成随机样本：在正方形内随机生成 $$n$$ 个点，记录落在圆内的点数 $$m$$。
3. 计算估计值：
   * 圆的面积与正方形面积的比值是$$\frac{\pi r^2}{(2r)^2} = \frac{\pi}{4}$$
   * 通过 $$\frac{m}{n}$$ 估计这个比值，$$\pi \approx 4 \times \frac{m}{n}$$
4. 增加样本数量：随着样本数量 $$n$$ 增加，$$\pi$$ 的估计值会越来越接近真实值

在未知 $$\pi$$ 的情况下，我们无法直接计算圆的面积，于是通过暴力采样和计算点数量的方式估计圆的面积，进而估计 $$\pi$$ 的值。
{% endhint %}

## 蒙特卡洛如何帮助我们处理复杂后验分布？

在求解后验分布的时候，我们经常要在分布上做一些计算，比如求期望、方差、或其他积分。但是如果碰上复杂分布、高维变量，计算就会变得特别困难。这时候我们就可以尝试绕过解析解，通过大量采样的方法直接得到统计量。

例如，我们想对一个连续随机变量 $$X$$ 求期望，概率分布函数为：

$$
p(x) = e^{-0.5 \cdot x^2} + \sin(x) + x^3
$$

那么道理上，它的数学期望就是

$$
\mathbb{E}[X] = \int xp(x)\,dx
$$

各位看到，这里面要求积分，然而这个积分是无论如何无法用解析解求出来的。那怎么办呢？我们换个思路，假设我们可以从 $$p(x)$$ 中采样得到很多 $$x_1, x_2, x_3, ...x_i$$，再利用大数定理（在本书中不做详细解释）求这些样本的均值，就可以近似该分布的期望：

$$
\mathbb{E}[X] = \int x p(x)\,dx\approx \frac{1}{n} \sum_{i}^{n} x_i \qquad\qquad\tag{5-2}
$$

同样，对于离散随机变量，期望通常通过对所有可能取值求和计算。虽然这不涉及连续情形中的积分困难问题，但当随机变量维度很高时，例如 $$X = (X_1,...,X_D)$$，其可能取值数量会随维度指数级增长，从而出现维数灾难。因此，我们也可以通过从分布 $$p(x)$$ 中采样来近似期望：

$$
\mathbb{E}[X] = \sum_k x_k p_k\approx \frac{1}{n} \sum_{i}^{n}x_i \qquad\qquad\tag{5-3}
$$

{% hint style="success" %}
一句话总结：当概率分布的表达式非常复杂，尤其是涉及难以处理的积分时，蒙特卡洛方法可以避开难求的解析解，而是通过大量采样进行暴力计算估计。
{% endhint %}

{% hint style="warning" %}
注意：这里我们已知概率函数 $$p(x)$$, 只是这个 $$p(x)$$ 可能比较复杂，直接积分比较难求。
{% endhint %}

## 蒙特卡洛的实际应用案例

我们不妨暂时把心理学放在一边，先通过一个模拟股票走势的代码案例，了解蒙特卡洛的基本用法。

假定某个股票目前的股价是 $$S_t$$ , 预测时间 $$\Delta t$$ 之后的股价 $$S_{t+1}$$，金融工程中有公式：

$$
S_{t+1} = S_t + \hat{\mu} S_t \Delta t + \sigma S_t \epsilon \sqrt{\Delta t}
$$

假定初始股价$$S_0=10$$，我们可以模拟一下，一年之后 (244 个交易日 ) 的股价分布。

1. 首先，定义初始状态和模拟次数。

```python
from scipy.stats import norm
import numpy as np
import matplotlib.pyplot as plt

s0 = 10. #刚买入的股价，初始状态
mu = 0.15 # 上涨的均值
sigma = 0.2 # 波动的幅度
nSimu = 10000 # 模拟多少次
nStep = 244 # 每一次模拟走多少步, 1年只有244个交易日
dt = 1/nStep # 由于公式中的单位是年，而一年中有244个交易日，所以dt是理想化的每次股价变化间隔时间。
```

模拟10000次，得到一年后的股价分布。

```python
price = np.empty((nSimu, nStep))
e = norm()
for i in range (nSimu):
    s = s0
    price[i, 0] = s
    for j in range(nStep):
        et = e.rvs() # (0,1)高斯分布中随机采样一个噪音项
        s = s + mu*s*dt + sigma*s*et*np.sqrt(dt) #股价的计算公式
        price[i, j] = s
```

画出一年后股价的分布。

```python
plt.hist(price[:,-1], bins=30, density=True)
plt.ylabel('pdf')
plt.xlabel('Price')
```

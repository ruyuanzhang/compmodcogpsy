# 5.1.3 马尔可夫链

## 什么是马尔可夫链？

> _未来只依赖于现在，而不依赖于过去。_

马尔可夫链是状态空间中从一个状态到另一个状态的转换的随机过程，用来描述一系列状态之间的转移概率。在转移过程中，下一个状态 $$x_{t+1}$$ 只和当前状态 $$x_t$$ 有关，和再之前的状态 $$x_{t-1}$$ 无关。

$$
P(x_{t+1}|x_t,x_{t-1},x_{t-2},...,x_t) = P(x_{t+1}|x_t) \qquad\qquad\tag{5-4}
$$

## 马尔可夫链：状态转移、稳态分布和细致平稳条件

在马尔可夫链中，有两个核心概念：状态转移与稳态分布。

***

我们下面用一个情绪变化的例子来理解这两个概念。

假定人的情绪有三种状态：高兴、一般和悲伤。在每个时间点，人的情绪可以在这三种状态之间转换，且此刻的情绪只和上一个时刻的情绪状态有关，与再之前的情绪无关。

我们可以用状态转移矩阵 $$Q$$ 来描述这种转换。&#x20;

在马尔可夫链中，随着状态转移过程，状态分布会发生什么样的变化呢？

假设在 $$t_0$$ 时刻的初始情绪概率分布为 $$p_0$$，状态转移矩阵为 $$Q$$。我们可以借助代码一步一步计算，来跟踪情绪的演化。

首先，我们定义一个情绪状态的初始分布 $$p_0=[0.5,0.3,0.2]$$。

```python
import numpy as np
# 定义初始状态p0
e = np.array([0.5, 0.3, 0.2])
```

然后，我们定义一个$$3\times 3$$的状态转移矩阵 $$Q$$，第 $$i$$ 行代表从第 $$i$$ 种情绪状态转移到三种情绪状态的概率。

```python
# 定义状态转移矩阵Q
Q = np.array([[0.9  , 0.075, 0.025],
              [0.15 , 0.8  , 0.05 ],
              [0.25 , 0.25 , 0.5  ]])
```

接着，从初始状态开始，以转移矩阵进行40次状态转移：

```python
# 状态转移
for i in range(40): 
    e = e.dot(Q)
    print(f'interation i={i}, {e[0]:.3f} {e[1]:.3f} {e[2]:.3f}\n')
```

你发现了吗？经过多次状态转移，情绪状态的概率分布最后会保持不变：$$p=[0.625,0.313,0.063]$$。

***

上面的例子是一个离散分布，所以描述其状态转移的是一个矩阵（状态转移矩阵）。如果是一个连续分布，那么描述其状态转移的就是一个函数（状态转移函数）。

**由此，我们引出马尔可夫链的一个重要性质：**

> 在满足一定条件时，如果固定了状态转移矩阵（离散状态）或状态转移函数（连续状态），无论初始状态分布是什么， 多次迭代之后会收敛到一个稳定的分布。

也就是说，如果我们想要从一个目标分布采样，只需要找到其对应的状态转移矩阵（或者函数），然后哪怕随便从一个初始状态开始，通过不断状态转移就能够达到收敛。

**我们最后介绍马尔可夫链的细致平稳条件：**

满足以下条件的状态分布 $$p(x)$$ 就是状态转移矩阵（或函数）$$Q$$ 的细致平稳分布：

$$
p(x_1)*Q(x_2|x_1)=p(x_2)*Q(x_1|x_2) \qquad\qquad\tag{5-5}
$$

## 马尔可夫链在MCMC中的作用

在MCMC中，我们旨在构造一个马尔可夫链，其稳态分布就是我们想要采样的目标分布。

具体来说，沿着马尔可夫链采样：

1. 每一步只需要当前状态，不需要追踪过去整个状态历史。
2. 无论目标分布是否已知，只要找到正确的转移矩阵（或函数），理论上就能收敛到目标分布。
3. 细致平稳条件确保了我们设计的转移矩阵最终能够收敛到目标分布上。



下面我们还是用前面提到的情绪变化的例子，示例如何用代码进行马尔可夫蒙特卡洛采样。

定义初始情绪状态：

```python
# 定义一个初始状态
s = 0 # 3种情绪状态, s=0,1,2 注意这里的初始
# 定义状态转移矩阵Q
Q = np.array([[0.9  , 0.075, 0.025],
              [0.15 , 0.8  , 0.05 ],
              [0.25 , 0.25 , 0.5  ]])
```

设置预热期（burn-in）和采样的样本量（预热的目的是保证取样时分布已经稳定，所以一般会取比较大的数）：

```python
burnin = 1000000 # 被丢弃的burn-in samples
nSample = 1000000 ## 我们目标采集多少样本
samples = []
```

进行状态转移：

```python
for i in range(burnin + nSample):
    u = np.random.rand() ## 从(0,1)均匀一个值
    match s:
        case 0: ## 如果当前的状态为0
            if u <= 0.9: ## 有0.9的概率继续留在0
                s = 0 
            elif (0.9<u) & (u <= 0.9+0.075): ## 有0.075的概率0->1
                s = 1
            elif 0.9+0.075 < u: ## 剩下的概率0->2
                s = 2
        case 1: ## 如果当前的状态为1，以此类推，按照状态转移矩阵的信息来写判断
            if u <=0.15:
                s = 0
            elif (0.15<u) & (u <= 0.15+0.8):
                s = 1
            elif 0.15+0.8 < u:
                s = 2
        case 2:
            if u <=0.25:
                s = 0
            elif (0.25<u) & (u <= 0.25+0.5):
                s = 1
            elif 0.25+0.5 < u:
                s = 2
    samples.append(s) ## 每一次转换的状态，我们都保留下来
```

得到采样分布：

```python
import matplotlib.pyplot as plt
bins = [ -0.5, 0.5, 1.5, 2.5 ]
a, _, _ = plt.hist(samples[burnin:], bins=bins)
plt.xlabel('State')
plt.ylabel('Count')
print(a/nSample)
```

采样得到的分布接近马尔可夫链的稳态分布 \[0.625, 0.313, 0.062]：

```
[0.617709 0.339236 0.043055]
```

以上例子说明，我们可以利用马尔科夫链的性质来从一个目标分布中采样。在这个例子中，我们想要采样的分布是\[0.625 0.313 0.062]。我们利用其对应的转移矩阵 $$Q$$，然后随意假定一个初始状态（比如从0开始），然后根据转移矩阵 $$Q$$ 来不断地跳转，并记录每次得到的状态。迭代足够多次后，记录下的状态就会近似服从目标分布，从而达到采样的目的。

由于从任意初始点开始跳转时，马尔可夫链并不会一开始就服从目标分布，而是需要经过一段迭代过程才会逐渐收敛。因此，前面那些样本很可能来自还没有稳定下来的分布。实际操作中，我们会设置一个预热期（burn-in）：丢掉前面一部分样本，只保留后面的样本。这样做的目的，是让保留下来的样本更接近从目标分布中采样得到的结果。

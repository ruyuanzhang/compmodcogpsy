# 5.1.2 采样

前面讲了，蒙特卡洛方法的思路就是大量采样，用近似的“暴力计算”来解决问题，比如估计均值或期望。但问题来了：回到前面那个分布，

$$
p(x) = e^{-0.5 \cdot x^2} + \sin(x) + x^3
$$

这可是一个非常规的复杂分布，如何从这个分布中采样呢？下面就来介绍一些很多心理学学生可能不太熟悉的采样技巧。

## 什么是采样？

采样（sampling）指的是从一个概率分布中抽取样本的过程。如何判断我们是否成功从某个分布中采样呢？可以从两个直观要点来看：

1. 采出来的样本应该对应地是概率分布的 x 轴。
2. 当样本足够多时，把这些样本画成直方图，直方图的形状应该近似目标概率分布。

## 采样方法

一般来说，我们在Python或MATLAB等语言中可以很轻松的借助内置函数来从一些常见分布（例如高斯分布，Gamma分布等）中采样：

```python
from scipy.stats import norm,gamma
a = norm.rvs() # 从高斯分布中采样
print(a)
b = gamma.rvs(1) # 从伽马分布中采样
print(b)
```

以上的例子看到，我们只需要调用`rvs` 函数就可以达到采样的目的。可是你有没有想过，假如不允许使用这些函数，我们又该如何采样呢？

接下来我们以高斯采样的例子介绍几种常见的采样方法。

**问题**：只借助均匀分布$$[0,1]$$采样，如何利用该均匀分布从一个高斯分布中采样?

### _方法1：逆变化采样（Inverse Transform Sampling）_

{% hint style="info" %}
算法：

1. 从均匀分布$$[0,1]$$中采样，得到一个随机数 $$u$$：$$u \sim \mathrm{Uniform} (0,1)$$。
2. 将 $$u$$ 代入高斯分布的累积分布函数  $$F(x)$$ 的反函数： $$x = F^{-1}(u)$$，得到的 $$x$$ 就是需要获得的样本。
{% endhint %}

几乎所有的已知分布都可以用这种方法采样（其实Python和MATLAB内部就是这么做的）。

{% hint style="danger" %}
<mark style="color:$info;">问题：但是如果一个复杂分布，其累积分布函数的反函数未知，如何采样?</mark>
{% endhint %}

### _方法2：接受-拒绝采样（Accept-Reject Sampling）_

{% hint style="info" %}
采样前的准备：

1. 先找一个提议分布（proposed distribution）$$G$$，其概率密度函数 $$g(x)$$ 已知。提议分布可以是任意简单分布，例如高斯分布。
2. 再找一个常数 $$C$$，使得对于任意 $$x$$，都有 $$C \cdot g(x) \geq p(x)$$。

算法过程：

1. 从提议分布 $$G$$ 中进行采样，获取样本 $$x$$。
2. 从均匀分布$$[0, 1]$$中采样，得到一个随机数 $$u$$。
3. 如果 $$u \leq \frac{p(x)}{C \cdot g(x)}$$，那么我们就接受这个样本 $$x$$，保存下来；如果不满足，就拒绝并丢弃这个样本，重来。
{% endhint %}

以下是代码示例：

首先，设置目标采样分布的概率密度函数：

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import norm,uniform
# 目标采样分布的概率密度函数(已知但是很复杂)
def p(x):
    return ((0.3 * np.exp(-(x-0.3)**2))+0.7*np.exp(-(x-2.)**2/0.3))/1.2113
```

选定 $$C$$ 值和提议分布函数 $$g(x)$$，并画出分布。

plt.plot(x, p(x), color='r', label='p(x)')
plt.plot(x, C*norm.pdf(x, loc=1.4, scale=1.2), color='b', label='C*g(x)')

现在我们来采样:

```python
sample = []
nSample = 10000 ## 采集的样本数
for i in range(nSample):
    x = np.random.normal(loc=1.4, scale=1.2) ##先从G采样x
    u = np.random.rand() ## 再从[0,1]均匀分布采集一个判定标准
    if u <= p(x)/(C*norm.pdf(x, loc=1.4, scale=1.2)): ## 判断要不要留下x
        sample.append(x)
```

完成之后画出分布：

```python
x = np.arange(-3., 5., 0.01)
plt.plot(x, p(x), color='r', label='p(x)')
plt.plot(x, C*norm.pdf(x, loc=1.4, scale=1.2), color='b', label='C*g(x)')
plt.hist(sample, color='k', bins=150, density=True)
plt.legend()
plt.ylabel('p(x)')
```

```python
nSample = 10000
# norm和uniform函数都是产生一个正态或均匀分布的对象，可以搭配rvs函数等使用
uniform_rv = uniform(loc=0, scale=1)

sample = yy[mask] 
```

{% hint style="success" %}
接受拒绝采样的直观理解：&#x20;

* &#x20;$$C \cdot g(x)$$ 像一个罩住 $$p(x)$$ 的外壳。在每一个 $$x$$ 的点上, 都有 $$0 \leq \frac{p(x)}{C \cdot g(x)} \leq 1$$。从图上看，这个比值就是红线和蓝线的高度比。
* 每采到一个$$x$$ ，就计算这个比值，然后用$$[0, 1]$$之间的随机数来判断是否留下 $$x$$ 。
{% endhint %}

{% hint style="danger" %}
但是，接受拒绝采样需要找到一个准确的常数 $$C$$，如果这个常数 $$C$$ 无法直接得到怎么办？
{% endhint %}

### _方法3：Metropolis-Hasting采样_

{% hint style="info" %}
算法：

1. 从任意一个 $$x_0$$ 开始，&#x20;
2. 根据当前的样本 $$x_t$$ 构建一个提议分布 $$g(x | x_t)$$ （例如高斯分布），然后采样得到$$x^*$$。
3. 计算接受率 $$a = \min \left[ 1, \frac{p(x^*) \cdot g(x_t \mid x^*)}{p(x_t) \cdot g(x^* \mid x_t)} \right]$$。
4.  从均匀分布$$[0,1]$$采样一个随机数 $$u$$，

    \- 如果 $$u< a$$，则接受该样本 $$x_{t+1} = x^*$$

    \- 否则，继续维持原来的样本 $$x_{t+1} = x_t$$
5. 重复2-4步直到达到设定的样本总数。
{% endhint %}

在[MH采样算法证明](5.1.4-mcmcmh-cai-yang-suan-fa-zheng-ming.md)中会详细介绍该算法并解释它为什么成立，这里我们先来看看代码如何实现。

首先，设置目标分布的概率密度函数：

```python
from scipy.stats import norm
import numpy as np 

# 目标采样分布的概率密度函数
def p(x):
    return ((0.3 * np.exp(-(x-0.3)**2))+0.7*np.exp(-(x-2.)**2/0.3))/1.2113
    
nSample = 100000
sample2 = []

y = 1 # 设置初始值

#进行MH采样
for i in range(nSample):
    
    y2 = norm(loc=y).rvs() # 提议分布是一个高斯分布，以上一个样本y为均值，然后从中得到y2
    
    a = np.min([1, p(y2)*norm(loc=y).pdf(y2)/(p(y)*norm(loc=y2).pdf(y))]) # 因为提议分布高斯是对称的, 所以可以上下约掉

    u = np.random.rand() # 从[0,1]均匀分布获取一个值
    
    if u <= a:
        sample2.append(y2) # 接受并跳转到新的sample
        y = y2
    else:
        sample2.append(y) # 保留原来那个sample不变
        
# 绘制采样结果
x = np.arange(-3., 5., 0.01)
plt.plot(x, p(x), color='r', label='p(x)')
a,_,_=plt.hist(sample2, color='k', bins=150, density=True)
plt.legend()
plt.xlabel('X')
plt.ylabel('p(x)')
```

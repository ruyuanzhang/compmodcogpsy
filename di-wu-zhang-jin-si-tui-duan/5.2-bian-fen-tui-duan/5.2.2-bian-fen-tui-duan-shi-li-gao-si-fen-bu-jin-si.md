# 5.2.2 变分推断实例：高斯分布近似

接下来，我们介绍一个变分推断的编程实例，以高斯分布作为近似分布。

目标分布是关于随机变量 $$X$$ 的概率分布 $$p(x)$$ ，假设该分布为一个混合高斯分布：

$$
p(x)=\frac{0.3 * e^{-(\theta-0.3)^2}+0.7*e^{\frac{-(\theta-2)^2}{0.3}}}{1.2113}
$$

```python
import numpy as np
# 定义目标函数
def p(x):
    return ((0.3 * np.exp(-(x-0.3)**2))+0.7*np.exp(-(x-2.)**2/0.3))/1.2113    
```

由于目标分布 $$p(x)$$ 作为后验分布是已知的，我们可以利用 [5.2.1 ](/broken/pages/xu6OZ9m8OnXv9Ou0gzyT)中的公式（5-17），通过最小化 KL 散度来寻找一个近似分布 $$q(x)$$：

$$
D_{KL}(q(x)||p(x))=\int \log(\frac{q(x)}{p(x)})q(x)dx
$$

这里我们尝试采用一个高斯分布 $$q(x)$$ 去近似 $$p(x)$$。假设 $$q(x)$$ 的均值为 $$\mu$$ ，标准差为 $$\sigma$$：

$$
q(x)=\frac{1}{\sqrt{2\pi}\sigma}e^{-\frac{(x-\mu)^2}{2\sigma^2}}
$$

对于给定的参数组合 $$(\mu,\sigma)$$，我们可以计算对应的 KL 散度。不过 KL 散度本身仍然包含积分。为了解决这个问题，可以使用上一节介绍的蒙特卡洛思想，通过大量采样来近似该积分。具体来说，我们从 $$q(x)$$ 中采样，得到 $$n$$ 个样本 $$x_1, x_2, \dots, x_n$$，然后分别计算每个样本 $$x_i$$ 在 $$q(x)$$ 和 $$p(x)$$ 下的对数密度差，最后对所有样本求平均：

$$
D_{KL}(q(x)||p(x))\approx\frac{1}{n} \sum_i^n \log(\frac{q(x_i)}{p(x_i)}) \qquad \qquad \tag{5-21}
$$

也就是说，我们不用真的去算积分，而是从 $$q(x)$$ 中抽很多样本，用这些样本上的平均对数密度差来近似 KL 散度。

代码如下：

```python
from scipy.stats import norm

eps = np.finfo(float).eps #一个大于0的极小值ε，保证在进行对数计算时大于0.

def lossfun(params):
    # q-高斯分布的均值与标准差
    mu = params[0]
    sigma = params[1]
    
    samplesize = 500 #蒙特卡洛法的采样数
    
    # 从q分布中采样
    ss = norm.rvs(loc = mu, scale = sigma, size = samplesize)
    # 样本在q分布的概率密度
    pp2 = norm.pdf(ss, loc = mu, scale = sigma) * 0.999 + eps 
    
    # 样本在p分布的概率密度
    pp1 = p(ss) * 0.999 + eps 
    
    dd = np.log(pp2)-np.log(pp1) 
    
    return dd.sum()/samplesize
```

接下来便可使用一般参数优化的方式，在参数空间 $$(\mu,\sigma)$$ 中求解 KL 散度最小对应的参数。

```python
from scipy.optimize import minimize
res = minimize(fun=lossfun,x0=(1,1),method='Powell',bounds=((-3,3),(eps,3)))
print(res.x)
```

参数优化的结果为 $$(\mu=1.174,\sigma=0.967)$$，两个分布的示意图如下。

```python
import matplotlib.pyplot as plt
x = np.arange(-3., 5., 0.01)
plt.plot(x, p(x), color='r', label=r'$p(\theta)$')
plt.plot(x, norm.pdf(x,loc=res.x[0], scale=res.x[1]), color='b', label=r'$q(\theta)$')
plt.legend()
plt.ylabel('pdf')
```

# 1.4 认知科学的基础——信息处理假设

在当代认知科学研究中，理解大脑如何处理信息成为了核心议题之一，而计算认知则逐渐成为这一领域的重要工具。通过模拟和量化认知过程，计算认知不仅能够帮助我们解答大脑如何进行信息处理的问题，还能提供新的视角来理解人类行为的复杂性。然而，要深入理解计算认知的必要性，我们需要从认知科学的基础假设开始，了解信息处理理论的核心思想及其面临的挑战，最终论证为何引入计算认知是不可或缺的。

认知科学的基础假设是将认知视为一个信息处理（information processing）的过程，即认知是一个计算过程，而这个计算过程的本质则是对信息的处理。关于我们如何进行信息处理，学术界存在多种不同的理论，其中最具代表性的是符号主义和联结主义。

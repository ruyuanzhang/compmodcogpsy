# 9.1 社会决策

在第七章“价值决策”中，我们已经介绍了效用函数、前景理论以及风险决策等基本概念。然而，现实中的人类决策从来不是在真空中进行的。我们每天都要面对他人的存在：无论是在与朋友交往、与同事合作，还是与陌生人竞争的过程中，我们都在进行复杂的社会认知与决策活动。

相比于仅参考收益和概率的价值决策，社会决策的过程要复杂得多。如下图所示，人类在进行社会决策时，通常需要综合考虑自身的社会目标以及所接收到的社会信息，并在决策完成后表现出相应的社会行为。社会决策并不是悬空发生的，而是建立在不同层级信念的基础之上：最上层是个体信念，即基于个人独特的生活经验、人格特征和认知方式形成的信念，这类信念因人而异，也更容易发生变化；中间层是文化信念，即特定文化、国家或社会群体中共享的价值观与行为规范；最底层是默认信念，它构成了整个系统的基础，指的是人类在进化过程中逐渐形成的、最基本且往往不经反思就会自动启用的假设与认知倾向。

关于社会决策的认知科学范式和模型有很多。在这里，我们从最经典的社会决策范式——**最后通牒博弈**——入手，来理解认知科学如何研究社会决策这一问题。

最后通牒博弈的内容如下：假设你有一位朋友作为提议者，邀请你共同做一笔生意，这笔生意总共可以带来10元收益。如果你接受他的提议，他将分给你4元作为报酬；但如果你拒绝这一提议，这笔生意将无法进行，双方都不会获得任何收益。

<figure><img src="../.gitbook/assets/image (171).png" alt=""><figcaption></figcaption></figure>

从理性人的角度来看，只要提议者给予的报酬高于零，接受提议都应当比拒绝更有利，因为接受至少可以获得部分收益，而拒绝则意味着双方都没有收益。因此，在纯粹追求自身利益最大化的假设下，提议者通常也会倾向于尽可能少地分配报酬。然而，实验研究表明，现实中的人们并不总是这样选择。由于人们对公平性的高度敏感，当提议者提供的报酬明显低于总收益的比例时，提议往往会被拒绝。一般而言，当报酬低于总收益的20%时，拒绝率会显著上升。

针对这一实验现象，研究者提出了**公平厌恶模型**（Fehr & Schmidt, 1999）。该模型的核心观点是：人们在决定是否接受提议者的合作提议时，不仅关注自身收益，也会关注分配是否公平。换言之，当自己相较于提议者获得的收益过少或过多时，都会产生一定程度的厌恶感，并进一步影响最终决策。其核心公式如下：

$$
U_i=x_i-\alpha_i\max(x_j-x_i,0)-\beta_i \max(x_i-x_j,0)
$$

其中：

* $$x_i$$：响应者的收益；
* $$x_j$$：提议者的收益
* $$\$$$$\alpha_i$$：个体对不利不平等的敏感性参数；
* $$\beta_i$$：个体对有利不平等的敏感性参数；
* $$U_i$$：响应者的效用

$$
U = U_{accept} - U_{reject} = U_{accept} - 0
$$

最终，响应者接受提议的概率 $$P(i)$$等于：

$$
P(i)= \frac{1}{1+e^{-\gamma*U}}
$$

其中 $$\gamma$$为逆温参数，用于控制决策的随机性。

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import minimize

np.random.seed(2025)

class FehrSchmidtModel:
    def __init__(self, alpha, beta, noise=0.5):
        """
        Fehr-Schmidt 模型参数
        alpha: 不利不平等厌恶系数 (嫉妒, Envy) -> 当别人比我多时
        beta:  有利不平等厌恶系数 (内疚, Guilt) -> 当我比别人多时
        noise: 决策噪声 (Softmax温度参数 1/inverse temperature)
        """
        self.alpha = alpha
        self.beta = beta
        self.noise = noise # 这里的noise实际是 1/inverse temperature

    def calculate_utility(self, payoff_self, payoff_other):
        """
        计算 Fehr-Schmidt 效用
        U_i = x_i - alpha * max(x_j - x_i, 0) - beta * max(x_i - x_j, 0)
        """
        utility = payoff_self
        
        diff = payoff_other - payoff_self
        
        # 不利不平等 (别人拿得多)
        if diff > 0:
            utility -= self.alpha * diff
        # 有利不平等 (自己拿得多)
        else:
            utility -= self.beta * abs(diff) 
            
        return utility

    def get_accept_prob(self, offer_self, total=10.0):
        """
        使用 Softmax 函数计算由于效用决定的接受概率
        Ultimatum Game: 拒绝收益为0 vs 接受收益为Utility
        """
        offer_other = total - offer_self
        u_accept = self.calculate_utility(offer_self, offer_other)
        u_reject = 0 # 拒绝通常意味着双方都得0
        
        # Softmax: P(Accept) = e^(noise * U_accept) / (e^(noise * U_accept) + e^(noise * U_reject))
        prob_accept = 1 / (1 + np.exp(-self.noise * (u_accept - u_reject)))
        return prob_accept
```

接下来，我们通过定义几组参数来观察几种不同人格的虚拟被试的行为反应。其中，自私人格的被试的$$\alpha$$和$$\beta$$均为0，代表其不在乎分配的公平性，只在乎自己得到的钱；平均性人格的$$\alpha$$为2，$$\beta$$为1，代表其讨厌别人分配到的比自己的钱多，稍微有点内疚；嫉妒性人格的$$\alpha$$为4，$$\beta$$为0，代表其极度痛恨别人比自己多，但不介意自己多；最后，圣人人格的$$\alpha$$和$$\beta$$均为3，表示其对任何的不平等都很敏感。

```python
# 定义几种典型的人格参数 (Alpha, Beta, Noise)
scenarios = {
    "Selfish":      (0.0, 0.0, 2.0), # 不在乎公平，只在乎钱
    "Average":      (2.0, 1.0, 2.0), # 讨厌由于别人比自己多(alpha=2), 稍微有点内疚(beta=1)
    "Envious":      (4.0, 0.0, 2.0), # 极度痛恨别人比自己多，但不介意自己多
    "Saint":        (3.0, 3.0, 2.0) # 对任何不平等都非常敏感
}

plt.figure(figsize=(12, 6))
x_range = np.linspace(0, 10, 100) # Offer 从 0 到 10 元

for label, params in scenarios.items():
    model = FehrSchmidtModel(*params)
    probs = [model.get_accept_prob(x) for x in x_range]
    
    linestyle = '--' if "Noisy" in label else '-'
    linewidth = 3 if "Average" in label else 2
    
    plt.plot(x_range, probs, label=f"{label} [a={params[0]}, b={params[1]}]", 
             linestyle=linestyle, linewidth=linewidth)

plt.axvline(5, color='gray', linestyle=':', alpha=0.5, label='Fair Split (5:5)')
plt.title("Ultimatum Game Acceptance Probability under Different Parameters", fontsize=14)
plt.xlabel("Offer to Self", fontsize=12)
plt.ylabel("P(Accept)", fontsize=12)
plt.legend(fontsize=11)
plt.show()
```

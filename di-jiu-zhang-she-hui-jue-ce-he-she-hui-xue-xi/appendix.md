# Appendix

## 本章数学符号总结

| 符号               | 含义                  |
| ---------------- | ------------------- |
| $$U$$            | 个体效用                |
| $$\alpha、\beta$$ | 不利与有利不平等厌恶系数（嫉妒、内疚） |
| $$Q$$            | 对奖赏价值的估计            |
| $$r$$            | 实际获得的奖赏             |
| $$\delta^r$$     | 对奖赏估计的误差            |
| $$G$$            | 对他人慷慨度的估计           |
| $$A$$            | 个体拥有的资产             |

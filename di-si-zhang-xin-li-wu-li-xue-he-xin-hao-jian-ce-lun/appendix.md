# Appendix

## 本章数学符号总结

### 心理物理学与曲线

| 符号                                                        | 含义                 |
| --------------------------------------------------------- | ------------------ |
| $$x$$                                                     | 物理刺激强度             |
| $$y$$、$$P(x)$$                                            | 刺激强度为$$x$$时的正确反应概率 |
| $$n$$                                                     | Stevens 幂定律的幂指数    |
| $$\alpha$$                                                | 阈限参数               |
| $$\beta_{\mathrm{psy}}$$                                  | 心理物理曲线的斜率参数        |
| $$\gamma$$                                                | 基线猜测率              |
| $$\tau$$                                                  | 失误率（lapse rate）    |
| $$g$$                                                     | 阈限处的目标正确率          |
| $$k_{\mathrm{W}}$$                                        | Weibull 曲线的比例常数    |
| $$\operatorname{normcdf}(x,\alpha,\beta_{\mathrm{psy}})$$ | 正态分布累积分布函数         |
| $$e$$、$$\exp(\cdot)$$                                     | 自然常数及指数函数          |
| $$\log(\cdot)$$                                           | 自然对数               |

### 心理物理曲线拟合

| 符号                                           | 统一含义            |
| -------------------------------------------- | --------------- |
| $$\theta$$                                   | 待估模型参数          |
| $$\hat{\theta}$$                             | $$\theta$$ 的估计值 |
| $$p$$                                        | 单次回答正确的概率       |
| $$\mathrm{data}$$                            | 一串二元反应记录        |
| $$D$$                                        | 完整数据集           |
| $$d_i$$                                      | 第 $$i$$个观测或数据点  |
| $$n$$                                        | 总试次数            |
| $$k$$                                        | 正确试次数           |
| $$\binom{n}{k}$$                             | 二项系数            |
| $$p(D\mid\theta)$$、$$p(d_i\mid\theta)$$      | 给定参数的条件概率       |
| $$L(\theta)$$、$$LL(\theta)$$、$$NLL(\theta)$$ | 似然、对数似然与负对数似然   |
| $$f(x\mid\theta)$$                           | 参数化的心理物理函数      |
| $$\sum_i$$                                   | 对所有观测求和         |
| $$\arg\min_\theta$$                          | 使目标函数最小的参数取值    |

### 信号检测论

| 符号                                    | 统一含义            |
| ------------------------------------- | --------------- |
| $$d'$$                                | 辨别力             |
| $$M_s$$、$$M_n$$                       | 信号与噪音分布的均值      |
| $$\sigma$$                            | 标准差             |
| $$\mu_X$$、$$\mu_Y$$                   | 随机变量的均值         |
| $$\sigma_X^2$$、$$\sigma_Y^2$$         | 随机变量的方差         |
| $$\phi(z)$$、$$\Phi(z)$$               | 标准正态密度函数与累积分布函数 |
| $$z(p)$$                              | 概率对应的 z 分数      |
| $$P_H$$、$$P_M$$、$$P_{FA}$$、$$P_{CR}$$ | 击中、漏报、虚报、正确拒绝率  |
| $$Z_H$$、$$Z_M$$、$$Z_{FA}$$            | 对应的 z 分数        |
| $$C$$                                 | 决策标准            |
| $$P_{\mathrm{correct}}(C)$$           | 正确率             |
| $$P_{\mathrm{correct,max}}$$          | 最大正确率           |
| $$\beta_{\mathrm{LR}}$$               | 似然比             |
| $$\phi_H(C)$$、$$\phi_{FA}(C)$$        | 标准处的信号与噪音密度     |

### ROC、AUC 与 2AFC

| 符号                                             | 统一含义                                             |
| ---------------------------------------------- | ------------------------------------------------ |
| $$\mathrm{ROC}$$                               | 受试者工作特征曲线                                        |
| $$\mathrm{AUC}$$                               | ROC 曲线下面积                                        |
| $$x_{\mathrm{ROC}}$$、$$y_{\mathrm{ROC}}$$      | ROC 的横轴与纵轴                                       |
| $$Z_{\mathrm{AUC}}$$                           | AUC 对应的 z 分数                                     |
| $$x_0$$、$$x_1$$                                | 噪音与信号的证据抽样值                                      |
| $$X_0$$、$$X_1$$、$$X_2$$                        | 随机变量或其差值                                         |
| $$Z$$                                          | 标准化后的正态随机变量                                      |
| $$\mathcal{N}(\mu,\sigma^2)$$                  | 均值为$$\mu$$、方差为$$\sigma^2$$的正态分布                  |
| $$\mathrm{HR}$$、$$\mathrm{FAR}$$               | 2AFC 的击中率与虚报率                                    |
| $$Z_{\mathrm{HR}}$$、$$Z_{\mathrm{FAR}}$$       | $$Z_{\mathrm{HR}}$$、$$Z_{\mathrm{FAR}}$$对应的 z 分数 |
| $$P_{\mathrm{correct}}$$                       | 2AFC 的正确率                                        |
| $$x_{\mathrm{signal}}$$、$$x_{\mathrm{noise}}$$ | 信号与噪音强度                                          |
| $$x_{\mathrm{left}}$$、$$x_{\mathrm{right}}$$   | 左、右位置的刺激强度                                       |

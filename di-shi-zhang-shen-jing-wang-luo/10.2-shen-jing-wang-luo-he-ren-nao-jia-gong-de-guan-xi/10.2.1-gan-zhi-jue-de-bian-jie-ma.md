# 10.2.1 感知觉的编解码

神经网络为研究视觉、听觉等感知觉加工中的神经编码提供了计算工具。研究者可以比较模型与脑活动的表征结构，也可以利用模型提取的特征预测神经活动。**表征相似性分析**和**神经编码模型**是开展这类研究的两种常用方法。本节将通过具体实例，介绍如何将神经网络的内部表征与人脑活动联系起来，考察二者在信息表征上的对应关系。

## 表征相似性分析

表征相似性分析 (Representational Similarity Analysis，RSA）是一种比较不同系统内部表征的方法。其核心思想是：不要求神经网络中的某个神经元与人脑中的某个神经单元一一对应，而是比较两个系统对同一组刺激所形成的相似与差异关系。

假设向人和神经网络呈现相同的 $$N$$ 个刺激。对于人脑，可以提取某个脑区对每个刺激的活动模式，例如fMRI测量中多个体素的响应；对于神经网络，则可以提取某一层对每个刺激的激活模式。两个系统的表征维度可以不同，但刺激及其排列顺序需保持一致。

随后，在每个系统内部，分别计算任意两个刺激 $$i$$ 和 $$j$$对应的活动模式之间的不相似性。一种常用指标是相关距离：

$$
D_{ij}=1-\mathrm{corr}(\mathbf{x}_i,\mathbf{x}_j) \qquad (10-64)
$$

其中，$$\mathbf{x}_i$$ 和 $$\mathbf{x}_j$$ 分别表示同一系统对两个刺激 $$i$$ 和 $$j$$ 所产生的活动模式，一般为高维向量； $$\mathrm{corr}$$表示相关系数。将所有刺激对的距离排列起来，即得到一个 $$N\times N$$的**表征不相似性矩阵** (Representational Dissimilarity Matrix, RDM)，用于后续比较人脑与神经网络的表征结构。

$$
\mathrm{RDM}= \begin{bmatrix} 0&D_{12}&\cdots&D_{1N}\\ D_{21}&0&\cdots&D_{2N}\\ \vdots&\vdots&\ddots&\vdots\\ D_{N1}&D_{N2}&\cdots&0 \end{bmatrix}
$$

因此，RSA通过比较刺激之间的相似与差异关系，考察不同系统的表征几何结构。例如，如果网络某一层的 RDM 与人脑某个视觉脑区的 RDM 高度相似，就说明：在所选刺激和不相似性指标下，该网络层对不同刺激的组织方式与该脑区较为一致。实际分析中，可以进一步计算两个 RDM 之间的相关，例如：

$$
r=\mathrm{corr}(\mathrm{RDM}_{\text{brain}},\mathrm{RDM}_{\text{model}}) \qquad (10-65)
$$

RSA 因而以刺激之间的相似与差异关系为共同基础，使人工神经网络、人脑不同脑区和行为数据所反映的表征结构能够在统一框架下进行比较。

## 神经编码模型

与 RSA 比较表征结构不同，神经编码模型（Neural Encoding Modeling）直接建立刺激特征与神经活动响应的预测映射。其中，刺激特征从神经网络中提取，核心问题是：模型提取的特征能否预测人脑对未参与模型拟合的刺激所产生的响应？

根据记录方式，预测对象可以是电生理实验中单个神经元的放电响应、fMRI中单个体素的BOLD信号，或者是EEG/MEG中的某个通道的信号。这些测量反映的神经活动尺度不同，但都可以在“刺激特征—响应”的框架下建模。下文以针对fMRI的逐体素编码模型（voxelwise encoding model)为例，介绍如何为每个体素建立预测模型，并评估神经网络特征对其响应的预测能力。

假设神经网络某一层产生了一个特征向量 $$\mathbf{x}$$，某个体素对同一刺激产生的BOLD响应为 $$y$$。最简单的编码模型可以用线性回归表示：

$$
y=\mathbf{w}^{T}\mathbf{x}+b+\epsilon \qquad (10-66)
$$

其中，$$\mathbf{w}$$ 是该体素对应的回归权重，表示模型中各神经网络特征对预测响应的贡献；$$b$$ 是截距项，$$\epsilon$$ 是未被模型解释的残差，包括测量噪声等。模型利用训练数据估计 $$\mathbf{w}$$和 $$b$$，再使用新的刺激检验预测响应与实际响应的一致程度。因此，本例中预测脑活动的建模假设为: 单个体素的响应可以近似表示为多个神经网络特征的线性加权和。

假设一个视觉神经网络可以将输入图片转换成不同层的特征：

$$
\text{Image} \rightarrow \mathbf{x}^{(1)} \rightarrow \mathbf{x}^{(2)} \rightarrow \cdots \rightarrow \mathbf{x}^{(L)}.
$$

对于神经网络的不同层，可以分别提取特征，为每个体素建立模型，并在未参与模型拟合的测试数据上，计算预测响应与真实测量响应之间的相关性。如果某一层的特征能够的较好地预测某个脑区中体素的响应，就说明该层所包含的信息与该脑区的神经表征具有较强的对应关系。实际研究中通常会使用正则化线性回归，以处理神经网络特征维度很高且彼此相关的问题。

```python
# Define layers to extract activations
layer_dict = {
    'conv1': model.features[2],
    'conv2': model.features[5],
    'conv3': model.features[7],
    'conv4': model.features[9],
    'conv5': model.features[12],
    'fc1': model.classifier[2],
    'fc2': model.classifier[5],
    'fc3': model.classifier[6],
}

# Extract activations from each layer
activations_dict = {}
def get_activations(name):
    def hook(model, input, output):
        activations_dict[name] = output.detach().cpu().numpy()
    return hook
# Register forward hook for each layer
hooks = []
for name, layer in layer_dict.items():
    h = layer.register_forward_hook(get_activations(name))
    hooks.append(h)
# Forward propagation
with torch.no_grad():
    _ = model(input_tensor)
# Remove hooks
for h in hooks:
    h.remove()
```

### 表征相似性分析

RSA利用已有数据中的神经信号和已提取的神经网络激活，分别计算表征不相似性矩阵，再计算矩阵间的相关性：

{% code overflow="wrap" %}
```python
# Representational Similarity Analysis(RSA)

# Load brain responses
brain_responses = data['betas'].item()
roi_list = list(brain_responses.keys())

results = np.zeros((len(roi_list), len(layer_dict)))
for iroi, roi in enumerate(roi_list):
    # Compute brain RDM
    brain_rdm = pdist(brain_responses[roi], 'correlation')

    for ilayer, layer in enumerate(layer_dict.keys()):
        activations = activations_dict[layer]
        activations_normed = activations.reshape(activations.shape[0], -1)

        # Compute CNN RDM
        cnn_rdm = pdist(activations_normed, 'correlation')

        # Compute similarity between brain and CNN RDMs
        r, p_value = spearmanr(cnn_rdm, brain_rdm)
        results[iroi, ilayer] = r
```

### 神经编码模型

下面继续展示如何基于神经网络提取的刺激特征和人脑皮层反应构建神经编码模型。本例使用到了人脑视觉皮层的磁共振数据，其基本的记录单元是体素，因此构建的是逐体素的编码模型。

{% code overflow="wrap" %}
```python
# Generate Gaussian receptive field
def gaussian_2d(coords, A, x_0, y_0, sigma_x, sigma_y, C):
    i, j = coords
    rf = A * np.exp(-((i - x_0)**2 / (2 * sigma_x**2) + (j - y_0)**2 / (2 * sigma_y**2))) + C
    return rf / (rf.sum() + 1e-20)

# Pooling activations with Gaussian receptive field
def pooling_activations(activations, gaussian_params, roi, voxel):
    # Spatial pooling for convolutional layers
    if len(activations.shape) == 4:
        layer_size = activations.shape[2]
        i = np.linspace(-4.2, 4.2, layer_size)# NSD image size: 8.4 x 8.4
        j = np.linspace(4.2, -4.2, layer_size)
        i, j = np.meshgrid(i, j)

        gaussian_rf = gaussian_2d((i, j), *gaussian_params[roi][voxel])
        activations_pooled = np.sum(activations * gaussian_rf[None, None, :, :], axis=(2, 3))
    
    # Fully connected layers
    elif len(activations.shape) == 2:
        activations_pooled = activations
    else:
        activations_pooled = activations.reshape(activations.shape[0], -1)
    return activations_pooled

# Compute R2 score
def compute_R2(y_true, y_pred):
    ss_res = np.sum((y_true - y_pred) ** 2)
    ss_tot = np.sum((y_true - np.mean(y_true)) ** 2)
    return 1 - ss_res / ss_tot
```
{% endcode %}

该模型采用岭回归（ridge regression），假设每一个体素对某个图片的响应是该图片在神经网络中对应特征的线性加权组合。由此，每一个体素对应AlexNet的每一层都会构建一个模型，计算出一组权重。

{% code overflow="wrap" %}
```python
# Voxel-wise encoding models: Use ridge regression to encode brain responses with CNN activations
layer_names = list(activations_dict.keys())
# Load Gaussian receptive field parameters
gaussian_params = data['gaussian_params'].item()

# Record encoding results
encoding_results = {layer: {} for layer in layer_names}

for iroi, roi in enumerate(roi_list):
    brain_response = brain_responses[roi]
    for layer_name in layer_names:
        r2_values = []
        activations = activations_dict[layer_name]
        
        # Voxel-wise encoding
        for voxel in range(brain_response.shape[1]):
            # Pooling activations with Gaussian receptive field
            activations_pooled = pooling_activations(activations, gaussian_params, roi, voxel)
            # Split data into training and testing sets
            X_train, X_test, y_train, y_test = train_test_split(
                activations_pooled,
                brain_response[:, voxel],
                test_size=0.2,
                random_state=42
            )

            # Train ridge regression model
            ridge_model = RidgeCV(alphas=[0.001, 0.1, 1, 10, 100, 1000])
            ridge_model.fit(X_train, y_train)
            y_pred = ridge_model.predict(X_test)
            r2_values.append(compute_R2(y_test, y_pred))

        encoding_results[layer_name][roi] = np.mean(r2_values)   
```

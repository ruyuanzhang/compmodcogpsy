# 10.2.2 工作记忆

在拨打电话时，朋友刚刚报出的号码会在你脑中停留几秒钟，供你完成拨号；在心算 37×6 时，你需要先记住个位相乘产生的进位，再把它加到十位的结果上。这类在数秒到数十秒的尺度上保持并运用任务相关信息的能力，称为工作记忆（working memory）\[1]。工作记忆是一个内涵丰富的概念：它不仅包括信息的保持，还包括对信息的更新与操作、在干扰下的保护，以及容量的分配等。本节聚焦其中最基础的一个问题：**当外部刺激已经消失后，大脑靠什么把信息维持住？**&#x4E0B;文的实验和模型针对的都是这个"维持"（maintenance）问题，而不是工作记忆的全部。这个问题之所以尖锐，是因为神经元最快的电活动转瞬即逝——一个动作电位只持续约 1 毫秒，膜电位和常规突触电流的时间常数也只有几十到上百毫秒。单靠这些快速过程的被动衰减，几秒钟的记忆从何而来？我们将先回到提出这一问题的经典实验，然后亲手搭建一个循环神经网络（recurrent neural network，RNN）模型，定性地再现实验中的关键发现，最后介绍现代计算认知神经科学"训练 RNN、再分析它"的研究路线。

### 经典实验：延迟反应任务与持续放电

二十世纪七十年代初，Fuster 和 Alexander 在猴前额叶记录到一类奇特的神经元：在延迟反应任务中，即使刺激早已消失，它们仍在持续放电，直到猴子做出反应为止\[2]。Funahashi、Bruce 和 Goldman-Rakic 在 1989 年用眼动延迟反应任务（oculomotor delayed-response task）对这一现象做了系统而经典的刻画\[3]。如图10.2.2.1所示：猴子首先注视屏幕中心；随后 8 个可能位置之一闪现一个光点作为线索（0.5 秒）；线索消失后是约 3 秒的延迟期，屏幕上只剩注视点，猴子必须保持注视；注视点一熄灭，猴子要把视线跳向刚才光点出现的位置才能获得奖励。由于线索早已消失，正确的眼跳只能依靠对线索位置的记忆。

<figure><img src="../../.gitbook/assets/image (164).png" alt=""><figcaption><p>图 1  眼动延迟反应任务示意图。从左至右：注视；8 个可能位置之一闪现线索光点；延迟期（仅保留注视点）；注视点熄灭后，猴子向记忆中的线索位置做眼跳。</p></figcaption></figure>

这项研究有三个经典发现。第一，许多背外侧前额叶神经元在延迟期内维持着明显高于基线的放电率，从线索消失一直延续到反应开始，这被称为持续放电（persistent activity）。第二，许多具有延迟期活动的神经元表现出方向调谐：它们只在线索出现于某个特定方向附近时才持续放电，Funahashi 等人称之为"记忆野"（memory field）——就像视觉神经元有感受野一样，这些神经元"感受"的是一段被记住的方向\[3]\[4]。第三，放电与行为有关：在能够分析的错误试次中，如果猴子随后做出了错误的眼跳，相应神经元的延迟期活动往往较弱，并可能提前中断甚至缺失\[3]。Romo 等人后来进一步发现，当猴子记忆振动频率这样的连续量时，一类前额叶神经元的延迟期放电率随被记住的频率单调变化\[5]。这些研究使持续放电成为解释工作记忆信息维持的最有影响力的候选机制之一。

\
无论如何，持续放电首先带来一个计算问题：没有输入时，活动会以几十到几百毫秒的时间常数衰减回静息水平。单靠这些快速过程的被动衰减，很难把信息保持 3 秒之久。那么，跨越秒级的持续放电究竟是靠什么维持的？本节接下来要介绍的是最经典的一类答案：循环连接。后文还会看到，一些较慢的突触或细胞状态变量也可能承担类似的作用。

### 会衰减的神经元与自我维持的网络

我们用最简单的发放率模型来描述一个神经元的活动 a 如何随时间变化：

$$
\tau \frac{da}{dt} = -a + f(wa + I) \qquad (\text{}1)
$$

其中 $\tau$ 是神经元的内在时间常数（这里取 $0.1$ 秒），$I$ 是外部输入，$f$ 是把总输入转换为放电率的函数——输入为负时不放电，输入很大时放电率趋于饱和。关键的角色是 $w$：神经元通过突触把自己的输出又送回自己（或者等价地，一群性质相同的神经元相互兴奋）的连接强度。

若 $w = 0$，公式 1 就是一个Leaky Integrator：输入撤走后，$a$ 以时间常数 $\tau$ 指数衰减——换句话说，仅靠快速的被动衰减记不住。但当自反馈足够强时，情况完全不同：

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(2026)

def f(x):
    '''放电率函数: 输入为负时不放电, 输入很大时饱和于最大值 1'''
    return np.tanh(np.maximum(x, 0))

def oneUnit(w, T=3, dt=0.01, tau=0.1):
    '''单个自反馈强度为 w 的神经元, 前 0.5 秒给外部输入'''
    a, trace = 0.0, []
    for t in np.arange(0, T, dt):
        I = 1.0 if t < 0.5 else 0.0
        a = a + dt/tau*(-a + f(w*a + I))
        trace.append(a)
    return np.array(trace)

ts = np.arange(0, 3, 0.01)
fig = plt.figure(figsize=(5, 3.2))
for w in [0.5, 1.5]:
    plt.plot(ts, oneUnit(w), label=f'w = {w}')
plt.axvspan(0, 0.5, color='gray', alpha=0.25, label='input on')
plt.xlabel('Time (s)')
plt.ylabel('Activity')
plt.legend()
```

<figure><img src="../../.gitbook/assets/image (165).png" alt=""><figcaption><p>图2 单个神经元的活动轨迹。自反馈较弱（w=0.5）时，输入撤走后活动迅速衰减；自反馈足够强（w=1.5）时，活动在输入消失后自我维持。</p></figcaption></figure>

如图 2 所示，$w = 0.5$ 时输入撤走后活动在零点几秒内衰减殆尽；而 $w = 1.5$ 时，神经元的输出经反馈成为自己的输入，公式 1 由此多出一个稳定的非零高活动不动点：外部输入把系统从零活动状态启动起来，之后它靠自我兴奋停在这个高活动状态上，即便输入消失也不再衰减。

这里出现了一个值得专门强调的现象：**循环反馈造就的有效记忆时间尺度，可以远长于单元自身的内在时间常数**——$\tau$ 只有 $0.1$ 秒，高活动状态却原则上可以无限期维持。这种跨越时间的能力并不来自元件本身变“慢”了，而是反馈动力学的性质；这样一个无需输入即可自我维持的稳定活动模式，称为吸引子状态（attractor state）。需要说明的是，在这里选用的非线性函数下，当反馈足够强时，零活动状态对微小的正向扰动并不稳定，因此这个极简例子展示的是“循环反馈如何产生稳定的高活动状态”，而不是一个同时拥有稳定“静息态”与稳定“激活态”的完整双稳态记忆开关。用回路的反复激励（reverberation）来保持记忆的思想可以追溯到 Hebb\[6]；此后，“循环连接—吸引子”框架逐渐发展成解释持续放电的最有影响力的一类计算理论\[7]。

不过，延迟反应任务要求记住的不是“有没有见过光点”，而是光点的方向——一个连续变量。这就需要把一个自我兴奋的神经元推广成一群相互作用的神经元。仿照 Ben-Yishai 等人提出、后来被 Compte 等人用于工作记忆建模的环形网络（ring network）\[8]\[9]，我们让 $N$ 个神经元各自偏好一个方向 $\theta\_i$，均匀铺满整个圆周，并按“偏好相近者相互兴奋、偏好相远者相互抑制”的原则设定连接：

$$
\tau \frac{dr_i}{dt}=-r_i +f\left(\sum_j W_{ij} r_j +I_i \right) \qquad{(2)}
$$

$$
W_{ij}
=
\frac{J_0 + J_1 \cos(\theta_i-\theta_j)}{N} \qquad{(3)}
$$

公式 2 只是把公式 1 从一个神经元推广到了 $N$ 个；公式 3 中，$J\_0 < 0$ 提供作用于所有神经元的全局抑制，$J\_1 > 0$ 提供随偏好差距增大而衰减的局部兴奋。

需要说明两点。第一，这里的 $W\_{ij}$ 更适合理解为单元之间的有效相互作用（effective coupling），而不是逐条对应真实皮层中的单突触连接：同一个单元对近邻是兴奋、对远处是抑制，这在真实皮层里一般不会由同一个神经元直接实现——在经典皮层回路模型中，通常假定同一神经元的快速突触作用具有一致的主要符号（Dale 型约束）——远距离的负作用应理解为经抑制性中间神经元介导的净抑制效应。

第二，这是一个高度理想化的机制模型——真实前额叶的有效连接当然不会严格长成公式 3 这样干净的余弦形状。它的价值在于，用最少的要素（局部兴奋 + 全局抑制）给出一种机制性解释：持续放电和记忆野可以**如何**从循环动力学中产生。写成代码只有几行：

```python
N = 100
theta = np.linspace(-np.pi, np.pi, N, endpoint=False)  # 每个神经元的偏好方向(弧度)

J0, J1 = -2, 8
W = (J0 + J1*np.cos(theta[:,None] - theta[None,:])) / N
```

### 复现延迟反应实验

现在让这个网络经历一个模仿 Funahashi 实验流程的试次：前 0.5 秒注视（无输入）；随后 0.5 秒在 90° 方向呈现线索——以 90° 为偏好方向的一小群单元收到额外的兴奋输入；线索撤走后进入延迟期。为了后面研究噪声的作用，我们在活动更新中留了一个噪声项，并用一个非负约束保证"放电率"不出现负值：

```python
def runTrial(cue_rad, delay=3.0, sigma=0.0, dt=0.01, tau=0.1):
    '''模拟一个延迟反应试次 (线索方向 cue_rad 以弧度给出),
    返回时间轴和所有神经元的放电率矩阵'''
    r = np.zeros(N)
    ts = np.arange(0, 1.0 + delay, dt)   # 0-0.5s 注视, 0.5-1s 线索, 之后为延迟期
    R = np.zeros((ts.size, N))
    for k, t in enumerate(ts):
        I = 1.5*np.exp(3*(np.cos(theta - cue_rad) - 1)) if 0.5 <= t < 1.0 else 0.0
        noise = sigma*np.sqrt(dt)*rng.normal(size=N)
        r = np.maximum(r + dt/tau*(-r + f(W@r + I)) + noise, 0)  # 放电率不为负
        R[k] = r
    return ts, R

ts, R = runTrial(cue_rad=np.pi/2)
print('线索结束时的峰值放电率:', round(R[100].max(), 2))
print('延迟期结束时的峰值放电率:', round(R[-1].max(), 2))
```

```
线索结束时的峰值放电率: 0.98
延迟期结束时的峰值放电率: 0.79
```

线索消失 3 秒后，网络里仍有一群神经元在高水平放电。把所有神经元的活动随时间画成热图：

```python
fig = plt.figure(figsize=(6.5, 3.4))
plt.imshow(R.T, aspect='auto', origin='lower', cmap='viridis',
           extent=[0, ts[-1], -180, 180])
plt.colorbar(label='Firing rate')
plt.axvline(0.5, color='w', ls='--', lw=1)
plt.axvline(1.0, color='w', ls='--', lw=1)
plt.xlabel('Time (s)')
plt.ylabel('Preferred direction (deg)')
```

图3在定性特征上与 Funahashi 实验中的观察一致：线索激起了一个以 90° 为中心的活动峰（bump），线索撤走后，活动峰不仅没有消失，还以略低的幅度稳定维持了整整 3 秒——网络产生了持续放电。请注意，网络中每个单元的时间常数只有 0.1 秒，但由于偏好相近的单元不断相互激励，"峰"作为一个整体成了网络的稳定状态；而峰停在哪里就编码着哪个方向——换一个线索方向，同样的网络会在相应位置维持一个峰。在连续极限下，这样一个对称的环形网络拥有一族由方向连续标记的稳定状态，因此这类模型被称为连续吸引子（continuous attractor）或"峰吸引子"（bump attractor）模型\[9]；我们这里的 100 个离散单元，是这一图景的数值近似。接着复现"记忆野"：给网络依次呈现 8 个方向的线索，统计每个神经元在延迟期最后 1 秒的平均放电率，就得到它的延迟期调谐曲线：

```python
cues_deg = np.arange(-180, 180, 45)      # 8 个线索方向(度)
delayAct = np.zeros((8, N))
for i, c in enumerate(cues_deg):
    ts, R = runTrial(cue_rad=np.radians(c))
    delayAct[i] = R[-100:].mean(axis=0)  # 延迟期最后 1 秒的平均放电率

fig = plt.figure(figsize=(5.2, 3.4))
for u in [12, 37, 62]:
    plt.plot(cues_deg, delayAct[:, u], '-o',
             label=f'unit {u} (pref {np.degrees(theta[u]):.0f})')
plt.xlabel('Cue direction (deg)')
plt.ylabel('Delay-period activity')
plt.legend()
```

<figure><img src="../../.gitbook/assets/image (167).png" alt=""><figcaption><p>图 4 网络中三个神经元的延迟期调谐曲线（"记忆野"）。每个神经元只为一小段线索方向维持延迟活动。</p></figcaption></figure>

如图4所示，每个单元都表现出局部的方向选择性：线索靠近其偏好方向时延迟活动较强，离得越远越弱，而不同单元的"记忆野"铺满整个圆周。这与 Funahashi 报告的前额叶记忆野在定性特征上相似\[3]——当然，这里只用 8 个方向粗略采样，得到的是粗粒度的调谐曲线；而且这是手工设计的模型产生的定性一致，不是对实验数据的定量拟合。

最后，猴子还需要把记忆变成行动。从网络中读出记忆方向最自然的方式是群体向量（population vector）：以每个神经元的放电率为权重，对全体神经元的偏好方向做（向量）加权平均：

$$
\hat{\theta}
=
\mathrm{atan2}\left(
\sum_i r_i \sin\theta_i,\;
\sum_i r_i \cos\theta_i
\right)
\qquad (4)
$$

```python
def decode(r):
    '''群体向量解码: 由全体神经元的放电率读出记忆的方向(度)'''
    return np.degrees(np.arctan2((r*np.sin(theta)).sum(),
                                 (r*np.cos(theta)).sum()))
```

眼跳只需指向 \$$\hat{\theta\$$ 即可。至此，我们定性地再现了经典实验的两个核心现象——持续放电与记忆野——并且模型为它们提供了一种机制性解释：局部兴奋加全局抑制的循环连接，足以让一群单靠自己"记不住"的单元集体保持一个连续变量。

### 漂移的记忆与行为误差

到目前为止网络是无噪声的，记忆可以完美保持。但真实神经元的放电充满随机涨落。把噪声加入模拟（runTrial 中的 sigma 参数）后，会发生一件微妙的事：活动峰作为整体依然稳定，但它的位置开始缓慢地随机游走。原因在于这个模型的动力学结构：在理想的对称环形网络中，峰停在任何方向上都同样稳定，沿着"环"的方向几乎不存在把峰拉回原位的恢复力——用动力学的语言说，这个方向近似是中性的——于是噪声投影到这个方向上的推挤便得以逐渐累积，形成随机扩散：

```python
fig, axes = plt.subplots(1, 2, figsize=(9.5, 3.4))
for i in range(10):
    ts, R = runTrial(np.pi/2, delay=6.0, sigma=0.05)
    dec = [decode(r) for r in R[100::10]]
    axes[0].plot(ts[100::10], dec, lw=1)
axes[0].axhline(90, color='gray', ls='--', lw=1)
axes[0].set_xlabel('Time (s)')
axes[0].set_ylabel('Decoded direction (deg)')

delays = np.array([1, 2, 4, 6])
sd = np.empty(delays.size)
for i, d in enumerate(delays):
    errs = [decode(runTrial(np.pi/2, delay=d, sigma=0.05)[1][-1]) - 90
            for j in range(50)]
    sd[i] = np.std(errs)

print('delay (s):', delays)
print('SD (deg) :', np.round(sd, 2))
axes[1].plot(delays, sd, '-o')
axes[1].set_xlabel('Delay (s)')
axes[1].set_ylabel('SD of memory error (deg)')
```

```
delay (s): [1 2 4 6]
SD (deg) : [0.65 0.91 1.4  1.76]
```

图 5展示了计算模型最可贵的一面：它不只是再现已有现象，还产生了新的、可检验的预测。如果记忆由理想连续吸引子上的活动峰承载，噪声就会推动活动峰沿中性方向随机扩散，最简单的扩散图景因而预测：记忆位置的不确定性会随延迟时间增加——在我们这个玩具模拟里，误差标准差确实随延迟单调增大（图5右）。当然，这一预测依赖于理想化假设，真实网络的异质性、残余的恢复力或系统性偏差都会改变漂移的具体形式。Compte 等人在 2000 年的模型工作中明确研究了空间工作记忆活动峰在噪声下的随机漂移\[9]；Wimmer 等人 2014 年进一步从模型推导出神经群体活动的逐试次波动与行为误差之间应有的关系，并在猴前额叶群体记录中观察到与"漂移的活动峰"解释一致的结果，为这一类机制提供了重要的实验支持\[10]。模型先行、实验检验——这是计算认知神经科学的一次经典配合。

### 持续放电是工作记忆的唯一机制吗？

到这里，我们已经形成一个等价观念：工作记忆 = 持续放电 = 吸引子网络。在进入下一节之前，我们必须先把这个等式拆开。持续放电与吸引子网络是解释工作记忆维持的最经典、机制最清晰的一类理论，但近二十年的研究表明，真实的图景要更丰富。

\
一方面，延迟期的神经编码不总是静态的。在一些任务中，研究者发现携带记忆信息的群体活动模式会随时间系统地演化：用延迟早期的数据训练的解码器，到延迟晚期性能可能明显下降——尽管在每个时刻都能从当时的群体活动中解码出记忆内容。也就是说，信息一直都在，但"写法"在变。Stokes 将这类现象概括为动态编码（dynamic coding）的框架\[11]，它与"一群神经元保持恒定放电"的静态图景明显不同。

\
另一方面，信息甚至可以在放电活动中暂时"隐身"。实验上，在某些延迟阶段，从当时的群体活动中直接解码记忆内容的信号可以变得很弱、甚至暂时检测不到，但随后通过新的输入或扰动又能重新显现。Wolff 等人在人类脑电研究中，于延迟期施加一个与任务无关的视觉"脉冲"刺激，发现从脉冲诱发的反应中可以解码出此前在自发活动中已难以读出的记忆内容，而且这种潜在状态与随后的行为表现相关\[12]。这类观察促使研究者提出"活动静默"（activity-silent）的工作记忆机制：信息可能被暂存在比放电更慢的变量里。一个代表性的机制候选来自 Mongillo 等人的理论模型——短时程突触易化在突触上留下的痕迹：即使神经元不再放电，被改变的突触状态也能在数百毫秒到数秒内保留信息，需要时再被重新激活\[13]。需要强调，突触易化是对这类现象的一种候选解释，而不是已被证实的唯一载体。

\
重要的是，这些机制并不互斥。它们可能分别对应不同的任务要求（信息是否需要随时可供读出）、不同脑区、延迟的不同阶段，甚至同一段记忆的不同成分。持续放电依然是许多任务——尤其是空间延迟反应任务——中稳健观察到的现象，吸引子网络也依然是理解它的核心理论工具；但"工作记忆必然表现为一成不变的持续放电"这一强版本的说法，在今天看来过于简单了。

### 训练而非设计：任务驱动的 RNN 建模

环形网络的连接是我们按照对答案的猜想手工设计的。但大脑的连接是学习得来的；而且面对更复杂的任务，研究者往往根本猜不出连接"应该"长什么样。另一条路线是：不设计连接，而是训练一个 RNN 去完成任务，训练成功后再分析它学到的解。用训练人工神经网络来对照神经数据的做法出现得很早——Zipser 和 Andersen 在 1988 年就用反向传播训练网络，并发现其隐藏单元的反应特性与后顶叶神经元相似\[14]。在现代"任务驱动 RNN"的研究中，最有影响力的代表性工作之一来自 Mante、Sussillo、Shenoy 和 Newsome（2013）：他们训练 RNN 完成一个情境依赖的知觉整合任务（注意，那个任务比本节的延迟反应任务复杂得多），再把训练出的网络动力学与猴前额叶群体记录相对照\[15]。Yang 等人进一步训练同一个网络完成 20 个认知任务，考察多种认知功能如何在一个网络中组织起来\[16]。

下面我们就在延迟反应任务上训练一个小型 RNN。网络动力学取公式 2 的离散时间版本（每一步活动衰减 $\alpha=\Delta t/\tau$ 的比例，再注入新的循环输入），主要的区别是：连接权重（以及各单元的偏置项）不再由我们指定，而是交给梯度下降去学。

与前面的环形网络不同，这里隐藏单元的活动是抽象的人工状态变量，取值可正可负，不应把单个人工单元逐点等同于一个生物神经元或它的放电率——我们真正关心的是网络整体的动力学。

先定义任务——每个试次共 30 个时间步，第 5–9 步用一对输入 $(\cos\theta,\sin\theta)$ 呈现线索方向，其后进入没有外部任务输入的延迟期（此时输入为零，网络的活动完全由循环连接和学到的偏置项决定），网络要在最后一步报告记住的方向：

```python
import torch
import torch.nn as nn

torch.manual_seed(2026)
np.random.seed(2026)

def makeBatch(B=64, T=30):
    '''生成一批延迟反应试次: 第 5-9 步呈现线索方向, 最后一步要求报告'''
    ang_rad = 2*np.pi*np.random.rand(B) - np.pi
    x = torch.zeros(B, T, 2)
    x[:, 5:10, 0] = torch.tensor(np.cos(ang_rad), dtype=torch.float32)[:, None]
    x[:, 5:10, 1] = torch.tensor(np.sin(ang_rad), dtype=torch.float32)[:, None]
    y = torch.tensor(np.stack([np.cos(ang_rad), np.sin(ang_rad)], 1),
                     dtype=torch.float32)
    return x, y, ang_rad
```

```python
class LeakyRNN(nn.Module):
    '''公式2的离散时间版本, 只是连接权重交给梯度下降去学'''
    def __init__(self, nHid=64, alpha=0.2):
        super().__init__()
        self.nHid = nHid
        self.Win = nn.Linear(2, nHid)
        self.Wrec = nn.Linear(nHid, nHid)
        self.Wout = nn.Linear(nHid, 2)
        self.alpha = alpha                 # alpha = dt/tau

    def forward(self, x):
        h = x.new_zeros(x.shape[0], self.nHid)
        H = []
        for t in range(x.shape[1]):
            h = (1 - self.alpha)*h + self.alpha*torch.tanh(
                self.Win(x[:, t]) + self.Wrec(h))
            H.append(h)
        H = torch.stack(H, 1)              # 每个时刻所有隐藏单元的活动
        return self.Wout(H[:, -1]), H
```

```python
net = LeakyRNN()
opt = torch.optim.Adam(net.parameters(), lr=3e-3)

for step in range(1501):
    x, y, ang_rad = makeBatch()
    yhat, H = net(x)
    loss = ((yhat - y)**2).mean()
    opt.zero_grad(); loss.backward(); opt.step()
    if step % 300 == 0:
        print(f'step {step:4d}: loss = {loss.item():.4f}')
```

损失迅速收敛。我们写一个测试函数来量化行为表现——在新试次上计算网络报告方向与真实方向之间的平均绝对角度误差：

```python
def testError(T, B=1000):
    '''在 B 个新试次上测试, 返回平均绝对角度误差(度); T 为试次总时长'''
    x, y, ang_rad = makeBatch(B, T)
    with torch.no_grad():
        out, H = net(x)
    out = out.numpy()
    err_rad = np.angle(np.exp(1j*(np.arctan2(out[:, 1], out[:, 0]) - ang_rad)))
    return np.abs(np.degrees(err_rad)).mean()

print('T=30(训练时长) 平均绝对误差:', round(testError(30), 1), '度')
```

```
T=30(训练时长) 平均绝对误差: 0.8 度
```

网络的"行为"非常准确。现在到了有趣的部分：像做电生理一样"记录"这个网络。我们先用 8 个方向的线索确定每个隐藏单元的"偏好方向"，再把单元按偏好排序，画出线索为 90° 的一个试次中全部隐藏单元的活动：

```python
def makeInput(cue_rad, T=30):
    '''单个试次的输入, 线索方向 cue_rad 以弧度给出'''
    x = torch.zeros(1, T, 2)
    x[0, 5:10, 0] = np.cos(cue_rad)
    x[0, 5:10, 1] = np.sin(cue_rad)
    return x

angs_deg = np.arange(-180, 180, 45)
with torch.no_grad():
    delayAct = np.stack([net(makeInput(np.radians(a)))[1][0, -1].numpy()
                         for a in angs_deg])   # 8 x 64
pref_deg = angs_deg[delayAct.argmax(axis=0)]   # 每个隐藏单元的"偏好方向"
order = np.argsort(pref_deg)

with torch.no_grad():
    H = net(makeInput(np.pi/2))[1][0].numpy()  # 线索为 90 度的一个试次

fig = plt.figure(figsize=(6.5, 3.4))
plt.imshow(H[:, order].T, aspect='auto', origin='lower', cmap='viridis')
```

图6中，线索一旦撤走，各隐藏单元的活动模式便变化得非常缓慢，一直保持到延迟期末——延迟早期与末期活动模式的相关系数达 0.91，而网络在最后一步又能准确报告方向，说明方向信息被网络保存了下来。没有任何人告诉它要这样做：为了完成任务，梯度下降自行找到了一种能够在训练所用的延迟长度内保存方向信息的循环动力学。看到这里，你也许想说：网络"发现了"吸引子！请先慢一点。回顾我们的训练设置：线索时机固定、延迟长度固定、只在最后一个时间步计算损失。在这样的条件下，延迟期活动看起来稳定，并不能证明网络形成了固定点（fixed point）或连续吸引子——它也可能只是学到了一段在训练时长内衰减得足够慢的瞬态轨迹（slow transient），或者其他只在有限时间内近似稳定的动力学。**任务完成得好，不等于我们已经理解了网络的机制。**&#x8FD9;是使用任务驱动 RNN 时最容易犯、也最需要警惕的推理跳跃。怎么检验？一个最简单的办法是把网络放到训练中从未见过的条件下——比如把试次长度从 30 步延长到 60 步。由于线索固定占据第 5–9 步，这相当于把线索之后没有外部任务输入的阶段从 20 步延长到 50 步，即原来的 2.5 倍：

```python
print('T=60(线索后阶段延长至 2.5 倍) 平均绝对误差:', round(testError(60), 1), '度')
```

```
T=60(线索后阶段延长至 2.5 倍) 平均绝对误差: 29.3 度
```

误差从 0.8° 恶化到约 29°：一旦明显超出训练时长，这个网络的记忆便迅速崩坏。长延迟下的失败说明，训练时观察到的稳定活动并不足以证明网络形成了一个能够无限期保持记忆的理想吸引子；但它同样不能唯一地告诉我们网络到底学到了什么——这一结果与缓慢瞬态、带有漂移或弱不稳定性的近似吸引子等多种动力学都相容。（反过来也要小心：如果延长延迟后误差依然很小，也只能说与吸引子解释"一致"，仍不构成证明。）更系统的检验思路包括：对延迟期的隐藏状态施加小扰动，看网络是否回到原来的记忆状态；在数值上寻找动力学的固定点或"慢点"（slow point）并分析其局部稳定性（例如对循环动力学做线性化、考察 Jacobian 矩阵的特征值）；以及考察不同线索方向对应的群体状态在状态空间中是否构成环状的流形。这类固定点与局部线性化方法被 Sussillo 和 Barak 系统地发展为分析训练后 RNN 动力学的通用工具\[17]；Mante 等人则把类似的动力系统分析用于情境依赖计算任务，揭示了训练出的网络如何组织与任务相关的循环动力学\[15]。这些"解剖"手段，正是把训练好的 RNN 从黑箱变成可研究对象的关键一步。另外值得注意：训练并不要求每个隐藏单元都具有简单、易读的单变量调谐。图6里单元层面的活动可以相当复杂，而任务变量往往要在群体层面的几何结构中才看得清楚。这正是现代计算神经科学的一个普遍转向——从逐个神经元的调谐曲线，走向群体活动构成的神经状态空间（neural state space）及其动力学。顺带一提，真实前额叶神经元常常对多个任务变量及其组合都有反应，这种性质称为混合选择性（mixed selectivity）\[18]；我们这个只有单一任务变量（方向）的简化任务，还展示不了这种现象。

### 小结

本节围绕"刺激消失后信息如何被维持"这一工作记忆中最基础的问题，走了一条完整的建模之路。经典延迟反应实验提示了持续放电与记忆野；对单个神经元的分析告诉我们，单靠快速膜电位和突触电流的被动衰减很难保持秒级的记忆，而循环反馈可以把有效的记忆时间尺度延长到远超单个单元的内在时间常数；手工设计的环形吸引子网络用"局部兴奋 + 全局抑制"为持续放电和记忆野提供了一种机制性解释，并预言了记忆漂移——这一预测得到了后来神经记录的支持。同时，现代研究也提醒我们：持续放电是最经典的候选机制，但未必是唯一机制，动态编码与"活动静默"的突触机制等较慢的状态变量可能在不同条件下参与信息维持。任务驱动的 RNN 展示了另一条路线：训练给了我们一个行为上胜任的人工系统，但真正的科学工作从训练结束才开始——检验泛化、分析群体几何、寻找固定点，并把由此产生的机制假设带回真实的神经数据。计算模型的价值，不止于复现已有的行为或神经现象，更在于把关于认知机制的语言描述，变成一个可以运行、可以扰动、能够产生新预测的系统。一个有解释力的模型应当把任务、行为与神经动力学连接起来，并提出可以由实验进一步检验的机制性预测：从任务到计算，从计算到神经动力学，再到行为与神经层面的预测，最后回到实验——这个闭环是本章的方法论核心，也会在全书中反复出现。
